# Somata 11.0.13 — Endpoint-safe Continuous Fillets

Сборка создана на основе **11.0.12**. Исправлен отдельный дефект системы скруглений Bézier, не затрагивая движение Morph.

## Исправление

У открытых контуров при достаточно большом скруглении ядро сглаживания соседнего **внутреннего** угла могло распространяться за начало или конец исходной линии. Например, у открытого профиля `(0,0) → (30,0) → (30,100)` при `baseEdge=100`, `rounding=200%` начальная точка смещалась на **8,08 геометрической единицы** при отключённом радиусном поиске. Это особенно заметно в спиралях.

Система теперь закрепляет исходную позицию и входящую/выходящую касательную каждого свободного конца. Для этого от сглаживания отнимаются две локальные **кубические функции Эрмита** с ограниченной опорой не дальше `min(width, perimeter/3)` от конца. На внутреннем крае зоны поправки значение и первая производная равны нулю (C1). Вычисление Bézier-кривых остаётся кусочно кубическим, без смены семейства алгоритмов и пересборки самого Morph.

При объединении последнего очень короткого сегмента сохраняется именно конечная исходная координата, а не координата его предшественника.

## Что не менялось

- Линейная интерполяция Morph, соответствия ключевых точек, N/K, фазовые таймеры, спиральный транспорт, принципы Монорадиуса.
- Скругление замкнутых контуров (350 сравнений Bézier-команд с 11.0.12 совпали в точности).
- Общий радиус, диапазон 0–200%, опция дополнительного скругления сплайнов и предельное падение максимального радиуса (по умолчанию 30%).

Из выполняемых JS-файлов изменён только `js/geometry/unified-fillet.js` (плюс версия ссылок ресурсов в HTML). Для тестов добавлены два отдельных файла.

## Ограничения

Проверены расчёты геометрии и браузерная отрисовка в программном Chromium, а не аппаратный WebGPU на машине пользователя. Для произвольных самопересечений не доказана глобальная G2-непрерывность. Точный сохранённый проект, давший первоначальный скриншот, отсутствует.
