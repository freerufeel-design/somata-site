# Somata 13.0.0 — геометрическая непрерывность фаз

## Базовая сборка

Somata 12.7.2, вариант **No Artificial Hold / No Test UI**. Никакого добавленного интерфейса диагностики или искусственного удержания конечных кадров в версии 13 нет.

## Исправление

В `js/geometry/morph.js` для обычных скруглённых Polygon Morph (`topology`, `calm`, `circleSlide`) добавлен отдельный слой преобразования **только выводимой кубической кривой**:

- Геометрии двух статических состояний записываются в кубические сегменты Безье.
- Когда динамический Morph представляет одну геометрическую кривую несколькими замкнутыми суборбитами, статические пути сопоставляются с ними без удаления или перестановки транспортных опорных точек.
- Пары Безье подразделяются по де Кастельжо, чтобы создать согласованную геометрию управляющих точек.
- Результирующая геометрия — интерполяция авторских статических кривых с полной фазовой коррекцией динамического остатка `4t(1-t)`. Эта функция не создаёт интервала неподвижных кадров. При `t=0` и `t=1` строится точная статическая кривая, без периода замораживания.
- Алгоритмы `getCircleMorphPlan`, угловых приращений, прямолинейного/углового движения, Circle Slide и спирального Morph не менялись.
- Если пара кривых не может быть надёжно согласована (например, неподдерживаемая топология), применяется прежний способ построения, **без ложного заявления о непрерывности**.

## Проверки

Проведены два набора по 24 последовательных перехода, каждый из восьми конфигураций (Topology, Circle Slide, Topo-Circle, сегменты / Spline / Spiral).

| Измерение | Результат |
| --- | --- |
| Точная граница `t=1 → t=0` | **48/48, 0 px** |
| Вблизи границы `t=.9999 → t=.0001` | До **5,0 px** |
| Строгий допуск 2,5 px для близких к границе состояний | **14 из 48 всё ещё выше допуска** |
| Координаты транспортных опорных точек | 168/168 совпадений с 12.7.2 |
| Искусственная остановка последних/первых кадров | Не обнаружена в контрольных состояниях |
| Стабильность дубликатов Spline+ | 135 сравнений пройдены |
| Прежние проверки Spiral C0 | Пройдены |

Запуск: `node tests/v1300-exact-phase-boundary.js`; для дополнительной последовательности: `SOMATA_PHASE_SEED=925341 node tests/v1300-exact-phase-boundary.js`. Отдельные отчёты приложены к сборке.

## ВАЖНО: что ещё НЕ доказано

**Somata 13.0.0 не подтверждена как полностью бесшовная во всех переходах.** Погрешность до 5 px сохраняется на близких к границе состояниях в тестовом GPU-рекордере. Это может быть связано с разной полилинейной аппроксимацией точно подразделённых Безье, но полностью исключить разницу самих кривых по этим тестам нельзя. Аппаратное WebGPU в доступном тестовом окружении не работало; реальный видеозахват не подтверждён. В некоторых редких топологиях алгоритм возвращается к прежней геометрии. Проект является рабочей сборкой для запуска, **не безусловно прошедшей весь строгий набор регрессионных тестов**.

Скругление и транспорт намеренно разделены. Программа не содержит диагностических кнопок.
