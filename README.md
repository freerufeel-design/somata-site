# Somata 12.7.2 — Static Target Locked Spiral Morph (экспериментальная)

Основа: полная Somata 12.7.1 со всеми прежними исправлениями Spiral/Fill.

Новый принцип для retained Spirals: исходная и целевая Bézier-геометрия
создаются до движения и используются как неизменные endpoints каждой фазы.
Для целевой спирали берутся **авторские узлы статической формы**, а не
временная matched/sampled сетка Morph. При normal Blue Morph интерполируются
точные подготовленные Bézier-сегменты; live-rounded построение по другим узлам
в середине фазы отключено. Время геометрического смешивания имеет гладкий
выход на обоих концах. Смена числа ветвей использует существующую стабильную
схему visibility и точную передачу предыдущего терминального Bézier rail.

Исправление нацелено на *скачок формы на стыке*, а не на косметическое
наложение/плавный fade разных картинок. Статический алгоритм Spline+ **не
изменялся** — пользовательское замечание о неидеально ровных статических
скруглениях остаётся открытой отдельной задачей.

В программной проверке — точное совпадение конечного и начального
отрисованных контуров в проверенных фазах; при сравнении с независимым
статическим target-рисованием нет несовпадающих точек линии вне
2-пиксельного допуска. Артефакты субпиксельного antialiasing при разбиении
Bézier могут отличаться, хотя траектория совпадает. Проверка физического
WebGPU/NVIDIA и абсолютной гарантии любых сочетаний ещё не выполнена.
Скорость FPS на NVIDIA не измерялась. См. `RELEASE_VALIDATION_12_7_2.md`.
