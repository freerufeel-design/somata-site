# Somata 13.0.26 — устранён рывок изогнутого профиля при Morph (02.11.2026)

Исправлен рывок при переходах «Отрезки ↔ Сплайн», который мог проявляться,
если профиль до запуска Morph имел изгибы. Раньше в середине фазы
менялась классификация стыков, а на границе 100% вместо авторского
контура мог отображаться выровненный/пересэмплированный Morph-профиль.

**Исправления:**
- Если меняется профиль (его форма и/или режим), но не орбитальная геометрия,
  при отключённых скруглениях Morph берёт реальные статические линии
  обоих состояний и плавно интерполирует их кубические сегменты.
  Это работает в обе стороны, в том числе с изогнутыми узлами.
- Для остальных смешанных переходов карта логических стыков больше не
  переключается дискретно на 50% фазы.
- Прежний алгоритм Spline+ при включённых скруглениях оставлен без изменений;
  спирали и специализированная геометрия используют прежний код.
- Все три режима времени перехода: «Вся фаза», «Начало фазы», «Конец фазы».

**Новый регрессионный тест:** `tests/v1326-bent-profile-mode-handoff-browser.js`.
Проверяются изогнутые профили, переходы в обе стороны, все три временных
режима, совпадение 100% с авторским статическим контуром и изменение
опорных узлов. Числовая проверка на ранее выпущенной сборке воспроизвела
рывок на 50% фазы; исправленный переход его устранил.

Пройдены тесты нового сценария, смешанных профилей Spline+, сплайнов без
скругления, эталонного Spline+ (2160 конфигураций), спиралей из плейлиста,
цветового Morph, синего ползунка и регистрация JS-модулей.
Аппаратный WebGPU отдельно не тестировался. Другие исторические
несовместимые тесты не объявлены исправленными.

# Somata 13.0.26 — Spline+ с нескруглёнными стыками и плавный Morph

Эта сборка основана на `Somata_13.0.26_Blue_Hue_Slider_Visible_Fixed.zip`.
Сохранены предыдущие исправления Blue Morph (смещение цвета и синие бегунки),
ограничителя шага и стыков спиралей, а также `default.plist` и тестовый набор.

## Новое: единый Spline+ для переходов «Отрезки ↔ Сплайн»

**При выключенных скруглениях (`rounding = 0`)** используется специальная
ветвь Spline+: один кубический сегмент на исходное ребро, неизменные узлы
и острые касательные только у логических стыков отдельных участков профиля.
Внутренние участки остаются настоящими плавными кривыми, а профиль
«Отрезки» — прямыми отрезками. Положение узлов не изменяется.

Morph использует **ту же ветвь Spline+** на всём промежутке `0…100%`:
постепенно меняются только управляющие точки Безье, с нулевой скоростью
изменения на границах диапазона. При `100%` результат побайтово совпадает
с обычным отображением сплайна. В обратном направлении используется та же
геометрия и тот же тайминг.

**При включённых скруглениях (`rounding > 0`)** остаётся исходный Spline+
в точности: сравнение 2160 конфигураций с утверждённым эталоном прошло.

Тайминги профиля в Blue Morph — «Вся фаза», «Начало фазы», «Конец фазы» —
сохранены. Для нереференсных режимов в окне перехода применяется smootherstep
пятого порядка для мягкого входа/выхода без скачка ускорения. Референсные
режимы `topology` и `calm` не изменялись.

## Исправление режима «Профиль: сплайн»

- **Скругления выключены (`rounding = 0`):** построение идёт по профилю Spline
  с кривыми Безье. У отдельных участков сохраняются исходные стыки без
  дополнительных скруглений (если включён отдельный режим `wholeCurveSpline`,
  сохраняется его авторское поведение).
- **Скругления включены (`rounding > 0`):** используется прежний Spline+
  без изменения утверждённой геометрии, ограничителей радиуса и Morph.
- **Профиль «Отрезки», `rounding = 0`:** по-прежнему прямые отрезки.
- Правило применяется и к обычной геометрии, и к Blue Morph / переходам
  между профилями, и к подготовке спиральных Bézier-сегментов для GPU,
  и к их семплированию для эффектов.

Изменены: `js/app/geometry-gpu-core.js`, `js/geometry/morph.js`.

### Дихром и равномерный режим линий

В палитрах плейлиста есть встроенная редактируемая «Дихром» (белый → зелёный → чёрный, мультипликатор 2).
Тип наслоения линии больше не переключается: всегда равномерный. При загрузке старых проектов значение `segmented` автоматически заменяется на `uniform`, включая GPU-отрисовку.

### Мобильный редактор профиля — 13.1.2

В режиме удержания заголовка «Профиль отрезка» редактор открывается в компактной нижней панели. Кнопка «Профили ▾» показывает категории с галочками Morph, под ней находятся выбор пресета, три равные кнопки «Отрезки / Сплайн / От руки», затем холст. Редкие функции находятся в раскрываемом блоке «Дополнительные настройки».

Ввод пальцем: тап по линии добавляет точку, перенос точки осуществляется касанием и движением, удержание точки без движения ~0.57 с с последующим отпусканием удаляет её. Если после долгого удержания начать двигать точку, панель становится на 80% прозрачной, пока палец не отпущен. На десктопе обычные мышиные жесты сохранены.

Прогнать мобильные проверки: `node tests/mobile-profile-touch-compact-1312-regression.js`.
