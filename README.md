## Изменения 10.2 — Mono Radius и Corridor

- **Монорадиус:** снято ошибочное ограничение минимального коэффициента коррекции `0.125`. На сильно растянутых профилях скругления теперь нормализуются к радиусу основной окружности; переключение режима и изменение скругления в активном Blue Morph обновляют геометрию с перебазированием кэша.
- **Corridor ON/OFF:** активация и выключение Corridor не меняют тип и порядок спирали. Большие/маленькие копии плавно появляются из действующей фигуры; при выключении — сходятся обратно в исходную фигуру.
- **Порядок спирали внутри работающего Corridor:** при переходе из ненулевого порядка к нулевому (и обратно, включая переход к/из обычного многоугольника) сначала сходятся копии Corridor, затем изменяется форма, после чего копии расходятся вновь. Только если один из **конечных** порядков равен нулю; при переходе между двумя ненулевыми порядками даже через промежуточный ноль популяция не запускается.
- Анимация изменения порядка относится к редактору геометрии при включённой галочке «Анимация». Для Blue Morph оставлена прямая фазовая интерполяция без обязательной промежуточной популяции; полная эквивалентность двух механик пока не заявляется.

Аппаратный WebGPU не проверен.

## Somata 10.4 — Переход к порядку спирали 0
- Новый выбор «Красивый / Честный» в левой панели спирали.
- «Красивый»: при действующем Corridor копии сворачиваются, профиль достигает 0, копии появляются обратно; «Честный»: прямое изменение порядка до математически точного 0.
- Ненулевой → ненулевой порядок не вызывает популяции, даже если промежуточный порядок пересекает 0.
- Один планировщик перехода используется Blue Morph и геометрической анимацией.
- Исправлены наложение полей «Спиральные слои» и закрытие всплывающего окна добавления связи кликом вне окна.
