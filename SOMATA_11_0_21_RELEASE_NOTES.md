# Somata 11.0.21 — Arc Cursor Fillets

**Цель:** уменьшить задержки при вычислении скруглений на повторно сглаженных и плотных фигурах, не меняя Morph и геометрию кривой.

- Потоковое объединение оригинальных точек и sampled spline-участков, без второго массива.
- Упорядоченный курсор для определения текущего ребра с корректным сбросом на замыкании.
- 1845 точных сравнений с 11.0.20 — без отличий в Bézier-командах.
- Повторные проверки рождения мини-профилей, начала и конца фаз, открытых и замкнутых спиралей, MonoRadius, касательной G1.
- Сохранено ограничение максимального падения радиуса, по умолчанию 30%, и диапазон 0–200%.

Ограничения и результаты измерений приведены в `RELEASE_VALIDATION_11_0_21.md`.
