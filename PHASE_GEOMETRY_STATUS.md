# Somata 12.7.2 — отмена искусственной фиксации кадров (экспериментальная сборка)

Эта сборка **не является полностью исправленным морфингом**. Она убирает недопустимую попытку скрыть разрыв фазы подменой и удерживанием кадров и возвращает честное поведение геометрии.

## Что удалено

- В `js/geometry/morph.js` удалено принудительное наложение статического контура на последние/первые 5,5% времени фазы (`canonicalEndpointPair`). На этих участках используется только текущая геометрия живого морфинга.
- Удалено принудительное присваивание `geometryT = 0` первому кадру после новой фазы (`firstVisiblePhaseFramePending`). Теперь всегда используется рассчитанное `SpiroMorphController.resolveBlueTimeline().geometryT`.
- Убраны маскирующие 2,5%/1,5% Canvas2D-кроссфейды статических концов для точного кубического морфинга и скруглённых сегментов. Внутри фазы строится один реальный геометрический контур без наложения неподвижного.
- Из `index.html` удалён скрипт диагностики. Сам `js/debug/adjacent-phase-visible-frames.js` и три связанных теста панели/захвата удалены из приложения. В интерфейсе нет тестовых кнопок и панелей.

## Что оставлено

- Исходные правила движения вершин и выбора сопоставлений, включая режим «По окружности» и Spiral.
- Исправление дублированных точек Spline+ из предыдущих итераций.
- Внешние самостоятельные тесты в `tests/` (не загружаются в интерфейсе).

## Проверено

Команды выполняются из папки с `index.html`:

```bash
node tests/v1272-no-hidden-phase-hold-regression.js
node tests/v1272-duplicate-stable-spline-morph-regression.js
node tests/v1272-morph-duplicate-draw-browser-regression.js
node tests/v1272-static-target-strict-endpoint-regression.js
node tests/v1270-exact-terminal-spiral-phase-regression.js
node tests/v1272-zero-rounding-boundary-regression.js
```

Все перечисленные проверки прошли. Проверка `v1272-no-hidden-phase-hold-regression.js` контролирует изменчивость записанных GPU-контуров на t=.9,.94,.96,.98,.995,.999,1 и на t=0,.005,.02,.04,.08 и отсутствие скрытых флагов/кроссфейдов.

**Важно: тест `node tests/v1272-real-gpu-command-recorder-boundary-regression.js` всё ещё FAIL — 12 из 24 фазовых границ (8 конфигураций × 3 границы).** В частности, максимум:

- Топология, Spline: 10,00 px;
- По окружности, Spline: 11,18 px;
- По окружности, сегменты со скруглением: 10,20 px;
- Спираль: 0 px в двух проверенных сценариях.

Метрика: симметричное пространственное расстояние между центрами нарисованных линий при масштабе 0,5 в холсте 800×800, допуск 1,5 px. Подробный JSON: `tests/v1272-real-command-recorder-boundary-report.json`. Контроль без скругления (`rounding=0`) в том же тестовом окружении дал не более 1,414 px в четырёх сценариях. Следовательно, оставшийся основной дефект связан с зависимостью построения закруглений от сменившегося каркаса точек. Его нельзя считать устранённым.

Сравнения выполнены на геометрических командах GPU-рекордера. Реальный аппаратный WebGPU в тестовой среде недоступен. Не следует трактовать перечисленные цифры как замеры с экрана пользователя.
