# Somata 12.3.0 — Circle Limit Fillets

При 200% полностью скругляемый замкнутый контур становится окружностью. Для открытых спиралей и явно острых углов режим прежний. В диапазоне 100–200% переход выполняется через smoothstep со сглаживанием положений и касательных, без смены опорной геометрии Morph.

В тестах построение окружности из 5000 точек на ровно 200% сократилось с 5,33 до 0,21 мс (локальное CPU-измерение, не FPS). При 100–190% рассчитывается прежний сложный контур, поэтому существенное падение FPS там ещё возможно.

См. `RELEASE_VALIDATION_12_3_0.md`.
