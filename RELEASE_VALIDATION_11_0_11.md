# Somata 11.0.11 — протокол регрессионного тестирования

## Новые тесты

| Команда | Результат |
|---|---|
| `node tests/v1111-radius-micro-phase-stress-regression.js` | PASS — 3995 пар соседних фаз на рандомизированных острых и коротких контурах; максимум 0,000256 геом. единицы |
| `node tests/v1111-low-radius-budget-phase-regression.js` | PASS — 3995 пар с очень строгими бюджетами радиуса; максимум 0,000820 геом. единицы |
| `node tests/v1111-mini-profile-collapse-boundary.js` | PASS — 96 сравнений при проходе порога длины микроребра; максимум менее 0,000001 геом. единицы |

Генератор использует фиксированное зерно и независимую рандомизацию малых перемещений точек; порог сравнения 0,025 геом. единицы в новых стресс-тестах. Сравниваются одинаково параметризованные по длине контуры; для явно меняющейся сегментации отдельный тест использует двустороннее пространственное расстояние. Экстремальный случай при 0% допустимого падения исходно давал скачок ширины около 37 единиц; теперь устраняется.
