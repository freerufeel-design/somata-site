# Somata 11.0.16 — проверка непрерывности скруглений

База: 11.0.15. Исправлен только `js/geometry/unified-fillet.js` (внутренний ограничитель внешнего радиуса). Линейный Morph, фазовая логика, перенос спиралей и соответствие опорных точек остались прежними.

## Найденная проблема

Почти совпадающие соседние углы имеют почти противоположные скачки касательной, поэтому их суммарное влияние должно стремиться к нулю с длиной мини-ребра. Старая радиальная оценка рассматривала каждый отрицательный вклад отдельно и выкидывала положительный, компенсирующий его. При пересечении порога слияния короткого ребра это могло менять глобальную ширину скругления даже при практически неизменном исходном контуре.

В первом сохранённом примере два профиля различаются перемещением одного узла приблизительно на 7,6×10⁻⁸ единицы. В 11.0.15 расстояние между нарисованными кривыми — около 9,93 единицы, в 11.0.16 — около 0,00028 единицы.

Схема: 8 постоянных уровней ширины, вычисление суммарных радиальных смещений со знаками, накопление только отрицательной вариации радиального положения и выбор непрерывной границы на этой сетке. Отдельная малая монотонная поправка предотвращает переходы из-за неподвижных внешних вершин. Это не меняет исходные опорные точки Morph.

## Новые тесты

Из корня проекта:

- `node tests/v1116-micro-edge-signed-guard-regression.js` — PASS, 4 воспроизводимых старых сбоя, максимальное отличие соседних линий ~0,000283.
- `SOMATA_FILLET_SOURCE=/путь/к/11.0.15/js/geometry/unified-fillet.js node tests/v1116-micro-edge-signed-guard-regression.js` — ожидаемый **FAIL**, случай №299: ~9,929 единицы.
- `node tests/v1116-radius-safety-sweep-regression.js` — PASS, 1000 псевдослучайных открытых/замкнутых фигур; контроль радиального бюджета 30%, неизменности входных точек, финитности координат.
- Дополнительный локальный поиск: 3182 случая вокруг порога появления мини-ребра. Старый алгоритм давал до 9,91 единицы на сравнении по длине; у нового такой скачок не обнаружен. Для точных выводов по пространственной форме использован более плотный симметричный геометрический тест (72 пробы на Bézier-сегмент).

## Производительность и границы доказанного

Новый расчёт использует 8 точек по ширине радиального ограничителя. В приблизительном локальном тесте сложного замкнутого контура на 5000 узлов время геометрического построения было около 0,1 с; сравнение с 11.0.15 показало близкую величину, но показатель зависит от прогрева V8 и нагрузки. Это не измерение итогового FPS или работы аппаратного WebGPU.

Геометрические и браузерные тесты пройдены на проверенных конфигурациях. Строгая G2-непрерывность во всех случаях не гарантирована; высокочастотные многоточечные пилы требуют оптимизации. Конкретный файл проекта с исходного скриншота и аппаратный WebGPU не проверялись.
