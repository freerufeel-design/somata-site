# Проблеск: ядро и ореол

Изменено в 13.1.3 с учётом AudioLink/Outline/Menu Fix.

- Новые значения для нового проекта/слоя: прозрачность ядра 100%, толщина 105%, яркость ореола 77%, интенсивность 100% ×1, размер свечения 14.5 px ×1, мягкость 100% ×1. Цвет ядра и цвет ореола: белый.
- «Внешний вид проблеска» разделён на две вложенные панели: «Настройки ядра» и «Настройки ореола».
- Параметр `sweep.color` задаёт цвет ядра, `sweep.haloColor` задаёт цвет ореола; оба независимы.
- Цвет ореола поддерживается Bézier WebGPU, canonical WebGPU, обычным GPU-путём и Graffiti-профилем.
- Старые проекты без `haloColor` автоматически используют цвет ядра, сохраняя прежний внешний вид. В старых проектах числовые настройки не перезаписываются.
- Master синхронизирует выбор через существующий sweep-обработчик между слоями. Оба цвета сохраняются вместе с `sweep` при экспорте проекта.
