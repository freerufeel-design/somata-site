# Somata 8.20.4 — множители амбиентов / 3D, Corridor Glint, единый ПКМ

База: Somata 8.20.3. Изменения ограничены настройками новых экранных эффектов, общей матрицей, UI-маршрутизацией и GPU-отображением проблеска на маленьких копиях Corridor. Архитектура Morph/Geometry и 3D-модели не переписаны.

## 1. Множители параметров

- 25 отдельных множителей ×0.125 / ×0.25 / ×0.5 / ×1 / ×2 / ×4 / ×8 для всех существующих диапазонов и числовых настроек дождя, дихотомий, Рэйацу, облаков, а также стеклянной фигуры (размер, преломление, дисперсия, прозрачность, вращение, положение, наклон).
- ×1 по умолчанию. У каждого параметра собственное значение. Сначала применяются маршруты Morph/Audio к числовому значению и множителю, затем множитель учитывается при построении текущего рендера; базовые значения authored state не перезаписываются.
- Множители зарегистрированы в `js/core/parameter-routing.js` и как дочерние контролы в `js/core/parameter-matrix.js`, с поддержкой маршрутизации Blue/Orange/Audio. Сохранение и загрузка происходят через уже существующие `state.ambient/state.prism`.
- Группы «Амбиенты» и «Преломление» подключены к Audio Routing, чтобы каталог действительно соответствовал общей матрице.

## 2. Синий Morph

- Проверен исходный контракт `normalizeSizes:true` в `state.js`, заводских настройках и UI. **Для нового проекта «Сохранять пропорции размеров слоёв» включено**. Явно сохранённое пользователем отключение в старом проекте не перезаписывается.

## 3. Corridor Glint

- 8.20.3 уже обеспечивал упаковку всех не полностью прозрачных копий, не отсекая маленькие для `sweep`.
- Дополнительно исправлено субпиксельное исчезновение проблеска: в GPU-шейдерах canonical/Bézier для **копий Corridor** выставляется минимальная экранная толщина ~1 пиксель и минимальный радиус свечения (если свечение включено). На обычном статическом контуре новые пороги не действуют. Нулевая прозрачность копии по-прежнему сохраняется как отсутствие эффекта.
- Прогресс проблеска по-прежнему вычисляется общим scheduler/планом; отдельный цикл для каждой копии не вводится.

## 4. ПКМ на левой панели

- Обработчики амбиентов и фигуры перенесены в общий `[data-sidebar-mode]` contextmenu, как у прочих групп. Удалены дублированные подписки в `ambient-prism.js`, чтобы один ПКМ не мог переключить дважды.
- ЛКМ открывает настройки, ПКМ переключает набор амбиентов/видимость 3D, мобильное долгое удержание использует существующий обработчик.
