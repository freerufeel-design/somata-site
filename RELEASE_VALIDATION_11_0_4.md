# Somata 11.0.4 — протокол проверки скруглений

Дата: 2026-10-29. База: Somata 11.0.3. Цель: убрать «уши» соединительных скруглений, не меняя движение опорных точек исходной 10.4 и не вводя расхождений между Static и динамикой на границе фаз.

## Техническое исправление

1. `js/app/geometry-gpu-core.js` — `appendLocalSplineFillet`: два плеча скругления и исходная вершина определяют локальный треугольник. Управляющие точки кубики непрерывно проецируются в этот треугольник. В Static и Morph используется одна политика касательных; скачущие варианты «chord-facing static / exact live tangent» удалены. Данные транспортных точек не менялись.
2. `js/app/lamp-audio-core.js` — `roundPolylineForDraw`: удалена боковая двухкубическая U-петля, специально создававшая внешний выступ на почти развёрнутых углах. Оставлена ограниченная квадратичная кривая; существующий фактор ослабления скругления к 180° и предел R/2 не изменены.
3. Взаимодействие этих изменений с ручной анимацией, Blue Morph, профилями и кадрами фаз проверялось через реальные браузерные обработчики рисования.

## Новые регрессионные тесты

- `tests/v1104-bounded-rounding-no-ears-regression.js`: 120 вариантов угла и касательных; у всех контрольные точки и вычисленные точки кривой лежат в выпуклой области плеч + авторская вершина. Пройден непрерывный проход касательной (шаг 0,5°), нет скачка управляющих точек. Проверены 15 реальных построений с 10-м стандартным сплайновым профилем, N=8/10/12, K=1/2/3/5, при r=72%, с точным сравнением команд Static и динамического построителя на одной геометрии. Специальная боковая U-петля не создаётся.
- `tests/v1104-phase-edge-pixel-continuity-regression.js`: 12 переходов при неизменном скруглении 72%: «По окружности» / «Топологический» / «Спокойный», N/K 7/2→8/1, 8/3→10/3, 10/3→8/3, 8/1→8/1. Растровые кадры у t=0, t=0.00001, t=0.99999, t=1 совпали с соответствующими Static в тестовом Chromium (ошибка 0 для этих примеров). Это именно конечные кадры, не доказательство гладкости всех возможных промежуточных сцен.
- `tests/v1104-visual-fixtures.js`: визуальный вывод четырёх фигур N=8/10, K=3, 72%/120% через реальный Canvas2D; запуск `node tests/v1104-visual-fixtures.js`, опциональный путь `SOMATA_VISUAL_OUTPUT=/path/to/file.png`.

## Расширенный прогон

53 тестовых скрипта запущены в тестовом Chromium без GPU: **48 успешно завершились, 5 завершились ошибкой**. Все пять также завершаются ошибкой на неизменённой Somata 11.0.3. Новый регрессионный провал относительно этой базы не выявлен в выбранной выборке.

Проверены старые алгоритмы движения 10.4 (`v1101-104-original-motion-regression`, `v1101-104-flat-motion-regression`), фазовые концы, углы 180°, высокая степень скругления, MonoRadius, переходы Segments ↔ Spline, спирали и Corridor. Подробные результаты локального прогона в `somata_1104_logs/results.txt` и `extra-results.txt` (папка логов сохраняется отдельно от релизного архива).

### Пять старых ошибок, которые не скрыты

- `v10419-42-asymmetric-short-spline-segment-fillet` — прежнее неудачное построение несимметричного короткого сегмента.
- `v10450-linear-rounded-topology-suborbit-handoff-regression` — небольшое историческое несовпадение топологического оконечного кадра.
- `v10419-45-transient-cusp-continuity-regression` — исторически требует *именно боковую U-петлю*, что противоречит нынешнему требованию её убрать.
- `v10481-preserve-morph-anchor-motion` — эталон позднего изменения траекторий, конфликтует с приоритетом пользовательской исходной 10.4.
- `v764-spiral-static-round-fade-regression` — исторический конфликт в маске появления центральной спирали.

Все пять повторены на исходной 11.0.3 (одинаковый тип ошибки). Эти тесты не удалялись и не переписывались ради «зелёного» отчёта.

## Границы подтверждения

- Проверен **Chromium Canvas 2D с отключённым GPU**. Реальная аппаратная реализация WebGPU и конкретный драйвер пользователя не проверены.
- Нет пользовательского `.plist` проекта, в котором видны именно уши последнего скриншота; тестовые профили реконструированы из UI и стандартных пресетов. Источник отдельных пересечений может быть заложен в самом выбранном авторском профиле, а не в округлении, и его нельзя исправлять автоматически без изменения фигуры.
- Полный каталог из ~400 тестовых JS-файлов не прогонялся. Этот релиз не объявляется универсальным закрытием всех старых ошибок фаз.
