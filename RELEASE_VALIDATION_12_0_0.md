# Somata 12.0.0 — проверка релиза и неизменности плавности

Утверждённая 11.0.26 без модификаций исходной логики. Изменены только `index.html` (title и query-версии скриптов/стилей), `manifest.webmanifest` (name), `README.md`, `CHANGELOG.md`. Добавлены профилировщик `tests/v1200-rounding-cost-profile.js` и `PERFORMANCE_ROUNDING_SOMATA_12.md`.

JS, CSS и файлы `assets/` скопированы без изменения содержимого. Сохранены baseline Morph, интерполяция фаз, соответствие вершин, скругления и транспорт спиралей.

Базовые регрессии и сравнение SHA256 источников запускаются при упаковке, результаты см. в итоговом сообщении. Старые версии тестов/фактические результаты 11.0.26 указаны в `RELEASE_VALIDATION_11_0_26.md`.
