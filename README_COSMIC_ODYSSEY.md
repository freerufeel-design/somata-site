# COSMIC ODYSSEY / Somata 9.0.2

Авторский плейлист из **10 полноценных проектов Somata** на основе изученных 23 заводских проектов из 9.0.1. Это переработанные конфигурации с новыми цветовыми палитрами, сценами, разными эффектами и контролируемой сложностью; не просто переименование.

## Как запустить

1. Откройте `index.html` Somata 9.0.2 через обычный способ запуска приложения (если нужен WebGPU, используйте `https://` или `localhost`, не простой `file://`).
2. В панели плейлиста откройте **стандартный плейлист** — в этой сборке `default.plist` содержит COSMIC ODYSSEY.
3. Включите зелёный **Morph проектов** (`◇`): сценами теперь управляет встроенный Green Project Morph.
4. В этой версии есть и отдельный `COSMIC_ODYSSEY_10.plist`: его можно открыть как обычный файл плейлиста через меню.
5. Заводской список из 23 проектов сохранён как `STANDARD_ORIGINAL_23_PROJECTS.plist` — его можно открыть через то же меню.

## Тайминг

- Изначально BPM = **128**, Auto-TAP отключён. Это воспроизводимая отправная точка, а не утверждение, что любой трек играет на 128 BPM.
- Включено `syncTap`, длительность каждой сцены **64 доли** (при 128 BPM около **30 секунд**).
- Переход занимает последние **8 долей** (около **3,75 секунд**).
- Переход: `fade`, обеспечивающий надёжность между несовместимыми типами геометрии. Цикл плейлиста около **5 минут** при 128 BPM.
- При реальной музыке включите Auto-TAP либо задайте BPM вручную; обратите внимание, что каждый проект сохраняет совместимые настройки TAP, а общие параметры плейлиста переопределяют их при загрузке.

## 10 сцен

1. **NEBULA GATE** — трехслойная холодная неоновая космическая геометрия, Corridor, медленные облака.
2. **BLOOM PROTOCOL** — розово-золотой геометрический цветок, полупрозрачная Fill, аккуратный Glint и Rainbow.
3. **SILK MATRIX** — нефритовая геометрическая сеть Web, одна основная форма, без тяжелой Spiral/Corridor.
4. **INFINITE HELIX** — три точные strict Spiral, мягкий Corridor и умеренный Reiatsu.
5. **CLOCKWORK WHEEL** — многослойное янтарно-бирюзовое колесо, медленное вращение, Glint и мягкая Dichotomy.
6. **CRYSTAL HEART** — один светлый геометрический контур и трехмерная стеклянная сфера WebGPU с дисперсией.
7. **METEOR RAIN** — огненные спирали, легкие Particles, дождь.
8. **BLOOD ICE** — ледяная геометрия с алыми акцентами и редкой молнией, без предварительного проблеска (фикс 9.0.1).
9. **BASSLINE REACTOR** — кислотный зеленый, Corridor, ротация и быстрый акцент Glint.
10. **SINGULARITY CROWN** — трехслойная корона, Corridor, разноцветная Dichotomy/Rainbow и Reiatsu.

## Архитектурные особенности

- `FrameContour` и точный retained Spiral/Bézier сохранены; никаких замен Spiral CPU-полилинией.
- Движок и эффекты 9.0.1 сохранены, включая Stable Auto-TAP, фикс множителя Corridor и молнию без preflash.
- Исправлен ранее существовавший разрыв области видимости `noteMorphGpuPrepareWait()`: Green Morph больше не выбрасывает ReferenceError при первом тике.
- Тяжёлые варианты Web + многократный Corridor + Lightning намеренно разведены по разным сценам. Включение 3D Prism потребует рабочий WebGPU.

## Проверки и ограничения

- Проверена загрузка всех 10 проектов в Chromium в порядке плейлиста, состояние Morph/Spiral/Web/Lightning/Prism, и запуск Green Morph через реальный UI.
- Пройден статический JS syntax check и выборочные регрессии ядра (см. `RELEASE_9.0.2.md`).
- Экранный визуальный результат на физической NVIDIA GPU и реальные FPS не сертифицированы: software/headless Chromium не даёт достоверной оценки WebGPU-пикселей.
