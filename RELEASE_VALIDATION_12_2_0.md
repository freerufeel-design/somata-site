# Somata 12.2.0 — Polynomial Sweep Fillets: протокол

## Принципы

Эталон — Somata 12.0 (зафиксированная геометрия 11.0.26), затем 12.1 (разбиение 16 по умолчанию). Никакие алгоритмы линейного Morph, сопоставления точек, фаз и транспорта спиралей не изменялись. Новый быстрый расчёт **выключен по умолчанию**. Вкл./выкл. возможны только при остановленном Morph; параметр не хранится в проектах. Не изменены kernel, глобальный радиус и способ его ограничения.

Используется тот факт, что сумма локальных кубических влияний на промежутке между событиями тоже является кубическим полиномом: при переходе через границу локального влияния обновляются коэффициенты, а не суммируются все углы для каждого узла. Для численной устойчивости каждые 64 станции или при превышении 0,12 ширины влияния используется пересчёт локального полинома. Если профиль открытый, смешанный, слишком редкий или недостаточно устойчивый, выбирается существующий метод.

- **420** точных сравнений выключенного ускорения с 12.1; **224** сравнения полной плотности с утверждённой 12.0, одинаковые команды Bézier.

- Браузерная проверка: по умолчанию ускорение выключено, ручное включение/отключение, запрещено переключение при активном Morph.
- Обычные регрессии: 900 геометрических случаев; 351 сравнение фаз, два набора по 3995 близких фаз, 2374 проверки касательных, 3466 проверок частичных касательных, 270 открытых контуров/спиралей. Браузерные N=4/K=2: 24; спирали: 8 сценариев с 21 фазой; открытые спирали: 60; включение динамических углов: 84; микро-рёбра: 352.

## Производительность (только Node.js CPU, не FPS)

Медианы после прогрева: на 5000 вершинах окружность ~113,6 →18,6 мс (6,1 раза), волна ~80,4→15,9 мс (5,1 раза), пила ~5,3→5,9 мс (слегка медленнее); на меньших фигурах выигрыш непостоянен. Эти цифры зависят от вычислительной среды, нагрузки, режима скругления и профиля. На GPU полный путь не профилирован.

## Ограничения

- Быстрый способ не гарантирует побайтовую эквивалентность, G2-гладкость всех кривых или выигрыш на каждом профиле.
- Для открытых спиралей, частичных углов, динамических мини-профилей и нестабильных интервалов используется эталонный путь, чтобы не нарушить утверждённую плавность.
- Аппаратный WebGPU, пользовательский сохранённый проект и длительная сессия не проверены.
- В необычных сильно увеличенных контурах или если заметен артефакт, немедленно отключите эксперимент: это восстановит эталонную форму.
