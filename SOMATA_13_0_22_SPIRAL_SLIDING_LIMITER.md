# Somata 13.0.22 — пять режимов и ограничитель шага

Восстановлены режимы исходного меню:

1. Рваный (`torn`).
2. Неразрывный фикс N/K (`continuous`), с внутренним фейдом исходных и целевых ветвей.
3. Неразрывный фикс N (`phase`).
4. Неразрывный фикс K (`minimalTurn`).
5. Неразрывный фазово-окружностный (`phaseCircle`), со старым клонированием/слиянием.

Отдельный режим `fadeSpiral` убран из UI, старые проекты с ним переключаются на `continuous`.

**Ограничитель шага спирали** — настройка слоя, по умолчанию включена, число 2. Только вычисляемое K для построения спирали циклически ограничивается, сохранённое число K не меняется. При L=2: 1,2,1,2...; при L=3: 1,2,3,1,2,3...; при выключении используется исходный K. На дробном K во время Morph интерполируется между соседними целыми фазами (без разрыва на переходе L → 1).
