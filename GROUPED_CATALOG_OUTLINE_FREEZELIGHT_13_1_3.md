# Somata 13.1.3 — единый каталог: группировка / обводка / FreezeLight

## Каталог автоматизации

Связанные параметры теперь стоят рядом в существующих разделах, без дополнительных заголовков. Используются составные подписи:
- **Линия**: Линия · толщина; Линия · прозрачность; Линия · цвет; Заливка · прозрачность; Заливка · цвет; Свечение · размер; Свечение · интенсивность.
- **Обводка**: Обводка · число слоёв; Обводка · толщина; Обводка · цвет; Обводка · расположение.
- **Лампочки**: Фризлайт · длина хвоста; Фризлайт · интенсивность, соседние строки.

Общий порядок формируется в `js/core/parameter-matrix.js` и применяется в Blue Morph, Orange Morph и AudioLink. Регистр свойств: `js/core/parameter-routing.js`. Левая панель использует тот же реестр для цветной рамки и контекстного меню.

## Числовая обводка

Упразднён автоматизируемый переключатель `outline.enabled`. Вместо него маршрутизируется `outline.layerCount`: целое число от 0 до количества слоёв. Обводка рисуется у первых N слоёв, в порядке сцены. Ручной общий переключатель «Обводка» остался в панели как переключатель всего эффекта. Количество 0 отключает обводку во всех слоях даже при активном общем переключателе. Значение по умолчанию для старых проектов без поля `layerCount` — все слои.

Старый ID автоматизации `outline.enabled` удалён из каталога; для новой числовой модели переназначьте ранее созданные маршруты на `outline.layerCount`.

## FreezeLight

- `lamps.freezeTailSec`: длина хвоста в секундах (0,05–30).
- `lamps.freezeIntensity`: интенсивность хвоста в процентах (0–100), по умолчанию 100%.

Параметры участвуют в Blue Morph, Orange Morph и AudioLink. GPU-рендерер использует аудио/морфинг для фактического затухания и яркости накопленной истории. Интенсивность влияет на след и не уменьшает яркость текущих лампочек или независимого FreezeLight Rain. Для появления хвоста FreezeLight должен быть включён.
