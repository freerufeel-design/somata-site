# Somata 8.20.3 — независимый стеклянный 3D-слой, Corridor Glint, Blue Morph

Исходная база: Somata 8.20.1. Обновлены только относящиеся к задаче файлы.

## Новый 3D-слой

- WebGL2 canvas `prism3dLayerCanvas` добавляется к `mainContainer` отдельно от 2D-слоёв, их authored-state и геометрии. Он находится поверх финальной сцены; его видимость и состояние не зависят от включения Corridor, Morph или выбора 2D-слоя.
- Настоящие полигональные 3D-сетки и треугольники, матрица вращения, перспективная проекция, z-buffer и GPU fragment shader с прозрачным материалом и экранной рефракцией. Сфера по умолчанию (сразу включена в новом проекте).
- Шесть объектов: сфера, линза, куб, череп (стилизованный объём), додекаэдр, трёхмерный крест. Положение X/Y и наклоны X/Y доступны в интерфейсе и общем реестре параметров.
- Подготовлен `SomataPrism3D.registerMesh(mesh)` для будущего импорта пользовательских моделей: валидация вершин/граней, triangulation, верхние ограничения. Загрузчик OBJ/glTF и его UI пока не реализованы.
- При отсутствии WebGL2 включается существующий Canvas fallback. Нельзя путать fallback с 3D.
- Границы точности: настоящая 3D-геометрия и аппаратное depth-testing, но **не** ray tracing / физическая трассировка света. Преломление осуществляется через смещённую выборку изображения 2D-сцены, расщепление каналов является экранной хроматической дисперсией.

## Исправления интерфейса и Corridor

- ПКМ по розовой амёбе включает/выключает сохранённый набор амбиентов, не открывая панель. ПКМ по черепу включает/выключает стеклянный 3D-слой. ЛКМ продолжает открывать настройки; мобильное удержание также вызывает переключатель.
- Blue Morph: новый проект имеет `normalizeSizes:true` / «Сохранять пропорции размеров слоёв» включено. Явный выбор пользователя при чтении сохранённого проекта не перезаписывается.
- В Corridor убрано отсечение эффекта `sweep` по экранному радиусу/толщине отдельных копий. Проблеск/Lightning передаются всем **видимым по alpha** копиям, включая дальние маленькие; zero-alpha остаются отсеянными. Web и остальные эффекты сохраняют прежние пороги culling. При очень большом числе копий это может повысить GPU-нагрузку.
- При чтении проекта без секции prism используется сфера с включённым 3D-слоем; сохранённые настройки пользователя учитываются.
- Бамп `?v=8.20.3` у изменённых JS-файлов для предотвращения старого браузерного кэша.

## Проверки

- `node tests/v8203-independent-3d-and-corridor-glint-regression.js`: геометрия и финитность 6 объектов, вызовы GPU draw, отдельный canvas, импорт сетки, Corridor-упаковка 12/12 видимых копий и 11/12 при нулевой alpha, defaults Blue Morph и кнопки. Используется заглушка WebGL2; она проверяет команды/данные, **не реальные пиксели GPU**.
- `node tests/v8201-prism-render-commands-regression.js`: старый Canvas fallback продолжает работать.
- `node --check` для всех production JS.
- Полный браузерный набор/физическое изображение WebGL2 на пользовательской видеокарте и FPS не сертифицированы: загрузка тяжёлого приложения Chromium в этой среде зависала.

## Осталось

1. Визуальная сертификация 3D-прозрачности, refraction, ориентации нормалей и blend на аппаратном WebGL2 (Chrome/NVIDIA), и скриншот с несколькими 2D-слоями.
2. Прогон Corridor Glint со включённым Blue+Orange+Spiral на реальном WebGPU и контроль нагрузки при сотнях дальних копий.
3. Отдельный загрузчик OBJ/glTF/GLB, с контролем размера, геометрии и материалов; физическая дисперсия/толщина стекла — отдельный этап.
