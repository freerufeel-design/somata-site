SOMATA 7.11.16 — ГЕНЕРАЦИЯ ORANGE / ШАГ / ПАЛИТРЫ / ОСТАНОВКА / CORRIDOR FILL (22.10.2026)
====================================================================================

Параметрический реестр: js/core/parameter-routing.js
Единая матрица меню, поднастроек и ШАГОВ: js/core/parameter-matrix.js
Значения Blue/Orange/Audio хранятся независимо в профилях и состоянии приложения.

1) Orange Morph: явные активные диапазонные связи теперь сохраняют СВОИ
   сгенерированные значения при наследовании настроек эффекта из предыдущего
   поколения. Ранее копирование lamps/web/sweep перекрывало случайное значение.
   Семплы сохраняются только в runtime и не добавляются в файлы проектов.
   Для процентных диапазонов 0..100 используется целочисленный шаг ±1.
2) Единая матрица: stepFor(parameterId) возвращает {mode,step}:
   процентные параметры с типичным диапазоном до 100 -> линейный шаг 1,
   остальные параметры сохраняют прежний шаг, дробные множители отмечены
   как логарифмические и используют существующие механизмы UI.
   Динамические поля диапазона Blue/Orange получают шаг из общей матрицы.
3) Если композиция имеет больше слоев, чем выбранная палитра, цвета
   повторяются по циклу исходной палитры. Дополнительные оттенки больше
   не выдумываются. Пример RGB ×8: RGB RGB RG.
4) Ручная остановка Orange:
   Instant оставляет текущую сгенерированную композицию;
   в незавершенном Fade удаляется незавершенная цель и остается последняя
   полностью подтвержденная исходная композиция перехода;
   если Fade завершился, остается последний подтвержденный результат.
5) Corridor: отставание по палитре работает даже без накопительного
   изменения оттенка: по копиям используется следующий цвет палитры,
   причем альфа каналы исходных Line и Fill сохраняются.
   GPU native Corridor Fill больше не блокируется одним только фактом
   цветового отставания; для каждого отдельного copy инстанса Fill получает
   свой цвет и alpha. Baked interwinding Spiral Corridor Fill по-прежнему
   использует единый mesh/цвет и не имеет per-copy сегментации цвета.

ПРОВЕРКИ:
- Новый Chromium e2e: маршрут lamps.radius=17, Instant, Fade, процентный
  шаг, переход по RGB при 8 слоях, palette lag без накопления: PASS.
- GPU Fill source contract: PASS; реальное железо/драйвер не проверялись.
- Синтаксис всех 102 production JS: PASS.
- 10 из 11 прежних регрессионных сценариев: PASS. «Витраж» из
  v7107-orange-static-generation-presets-regression.js падает и на 7.11.15
  с той же причиной (недостаточное число залитых слоев) — не новая регрессия.

Открыто: отдельные задержки рендера, аппаратная проверка Fill+Lag,
поддержка смены цвета по копиям для baked Spiral Fill.

SOMATA 7.11.15 — ТЕКУЩИЕ ИЗМЕНЕНИЯ (21.10.2026)

как исторический журнал (старые числовые ограничения относятся к прежним версиям).

- Счётчик FPS не закрывает Orange, Blue и Green/Project Morph меню.

2. ОРБИТЫ — ДОЛЯ В ПРОЦЕНТАХ
- js/core/parameter-matrix.js: общий диапазон 1–100%, подпункт
  «Доля орбит (%)», те же поля и разметка у Blue и Orange.
- Пересчёт в количество на каждой фигуре индивидуальный:
    количество = ceil(НОД(N, K) × процент / 100).
  100% = все доступные орбиты; 1% = минимум одна.
- js/app/ui-project-runtime.js: Blue Morph и генератор Orange.
- js/app/geometry-gpu-core.js: тот же диапазон для Audio Routing.
- Значения Blue, Orange и Audio по-прежнему раздельные.
  Заводской Orange 100–100% сохраняет прежнюю полную геометрию.
  Старые абсолютные значения Orange (0–19) читаются при загрузке
  и преобразуются приблизительно для сохранения существующих проектов.
  Старые Blue-проекты с count override сохраняют старую логику,
  пока пользователь не отредактирует процентный диапазон.

3. ТЕСТЫ И РЕНДЕР
- Новый тест tests/v71115-orange-header-orbit-percent-regression.js
  проверяет настоящую компоновку с CSS, FPS, меню, профиль, орбиты
  на реальной генерации восьми композиций в Chromium.
- Старые тесты абсолютного количества орбит обновлены до нового
  контракта процентов, без удаления прочих сценариев.
- Геометрическая математика Spiral и Full-GPU не менялась;
  FPS-задержки рендера остаются отдельной открытой проблемой.
