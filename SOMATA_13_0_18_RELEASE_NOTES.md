# Somata 13.0.18 — сокращение избыточных спиральных копий Corridor

Основа: Somata 13.0.17.

## Проблема
В одном слое Spiral с активным Corridor создаются несколько геометрических ветвей, затем Corridor инстанцирует эти пути с разными масштабами. Опция «Плавное исчезновение за экраном» сохраняет несколько очень крупных внешних экземпляров. В отличие от обычного многоугольника, длинная спираль проходит рядом с центром даже у огромных экземпляров, поэтому её внешние экземпляры продолжают накладываться на экран. Glow увеличивает стоимость наложения.

## Правка
- Добавлен параметр **Коридор → Спираль: дальние копии**: целое 0–24, по умолчанию **2**.
- В программном контуре разрешение выводить спиральные Corridor-экземпляры за краем экрана ограничено заданным числом интервальных шагов. На последнем интервале экземпляр плавно растворяется (smoothstep по логарифмической позиции). Это не резкая обрезка по ID копии.
- Одинаковое затухание используется для Base / Glow / Fill / частиц и ламп; вычисление физического положения фокуса и счётчик фигур не меняются при бюджетировании.
- Обычный Коридор без спирали и сама геометрия каждой спиральной копии сохранены. Движение N/K и суперскругление не затронуты.
- Значение **24** почти полностью возвращает прежний предел отображения удалённых копий; **0** убирает все копии, уже пересёкшие экранную границу по масштабу внешней фигуры. Поскольку спирали проходят через центр, такой режим намеренно может изменять внешнюю композицию.

## Результат симуляции
Одна статическая спираль с N=14.98, K=5, S=2, order=1, Corridor distance=300%, travelPhase=0.35, extent=215, outer radius=950, software Chromium:
- До ограничения (24): 10 реально отрисовываемых экземпляров.
- Новый стандарт (2): 8 экземпляров.
- Минимум (0): 6 экземпляров.
- Число исходных геометрических путей — 6, их координаты не меняются.
- Эти цифры — снижение логического числа копий в конкретной сцене, **НЕ** аппаратный замер FPS. Другие размеры холста/масштабы/дистанции изменяют число копий.
