# Somata 11.0.26 — Monotone Arc Probes

Оптимизировано только обнаружение дополнительных скругляемых углов в режиме Morph. В предыдущей 11.0.25 поиск точки на входящей и выходящей дугах дважды выполнял бинарный поиск на каждую вершину. Теперь применяется два последовательных указателя, сбрасываемых только на замкнутом шве. Для нулевых и микро-рёбер сохранён тот же выбор участка.

**12 200 проверок:** полностью одинаковые вычисленные веса с оригиналом 11.0.25. Повторные тесты границ Morph, мини-профилей, спиралей, Монорадиуса и G1 прошли. 5000-точечный профиль в локальном тесте вычисления углов ускорился с ~1,24 до ~0,86 мс. Не изменены линейный Morph, вершины, их соответствия, N/K, фазы, транспорт спиралей и математический построитель скруглений.

Это ускорение времени обработки, **не исправление нового подтверждённого геометрического скачка**. Осталась небольшая зависимость смешанного замкнутого контура от места начала обхода; для безопасного исправления нужны дополнительные тесты. См. `RELEASE_VALIDATION_11_0_26.md`.
