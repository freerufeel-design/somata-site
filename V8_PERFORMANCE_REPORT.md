# Somata 8.0.0 — восьмая итерация: производительность и согласованность эффектов

Основа: исходный архив `Somata_7.11.16_orange_routes_steps_palette_corridor.zip`.

## Выполнено

1. Corridor: при выключенном накопительном смещении цвет движущихся копий вычисляется от **непрерывной позиции**, а между цветами активной палитры применяется линейная интерполяция RGB. Резкие скачки при пересечении целочисленного шага заменяются плавным переходом. Cumulative-семантика оставлена прежней.
2. Blue и Orange: каждая отображаемая строка параметров, включая специальные строки, показывает `Слои [0…100] %` рядом с диапазоном. По умолчанию 100. Набор слоёв случайно выбирается для параметра один раз на цикл Blue / композицию Orange. При 0% эффект не меняет соответствующие выбранному параметру слои.
3. Совместимость: значения добавлены в описания привязок Blue/Orange и состояние специальных параметров, сохраняемое в профилях. Старые профили без процента работают как 100%.
4. Производительность: режим 100% обходит рандомизацию/создание наборов в горячем `applyFrame`; для всех обычных Orange-настроек используется один общий набор слоёв при 100%; нет лишнего последнего копирования generated layers; post-mask не запускается при 100%; Corridor за один вызов разрешает сдвиг оттенка и не нормализует одну и ту же конфигурацию дважды.
5. Не менялись FrameContour, strict Spiral retained GPU carrier, RenderGraph и художественная математика Blue/Orange.

## FPS — Chromium с отключённым GPU, Desktop 1280×720

| Сборка | Медиана 3 прогонов |
|---|---:|
| Оригинал 7.11.16 | 5,55 FPS |
| 8.0.0 после оптимизаций | 5,72 FPS |

Наблюдаемое отличие +0,17 FPS (~3%). Это **не гарантированный прирост**: результаты зависят от нагрузки тестовой машины; рендер без аппаратного GPU не отражает поведение NVIDIA / WebGPU. Измерение на реальном устройстве остаётся обязательным.

## Ограничения и задачи следующего этапа

- Для параметров `frameTarget=global` (например, глобальный Hue Offset или параметры Corridor) процент есть в общей строке UI, но глобальная величина по определению не разбита по слоям. Их отдельная послойная маршрутизация требует осознанного изменения архитектуры и здесь не реализована. Не считать 0–100% полноценным послойным управлением **глобальными** параметрами.
- Переход палитры проверен вычислительно, но итоговые физические пиксели на пользовательской видеокарте не проверены.
- Нужна длинная аппаратная проверка сочетаний Corridor + Spiral + Morph + Web + Graffiti + Particles на реальном GPU и сравнение FPS/VRAM/frametime.
- Не заявляется закрытие исторического дефекта «Витраж» или аппаратных падений GPU.
