# Somata 9.0.6 — Lightning Trigger Sources

База: Somata 9.0.5. Существующие плейлисты не изменены.

## Режимы запуска молнии

В шапке «Молния» появился селектор «Привязка» (значение хранится в `sweep.lightningTriggerMode` отдельно для каждого слоя).

| Выбор | Приоритет / поведение |
| --- | --- |
| **Морфинг (авто)**, по умолчанию | Включённый проблеск → один удар при завершении полного оборота; иначе активный Blue/Orange Morph → привязка к его циклу; иначе обычный таймер |
| **Таймер** | Строгий самостоятельный таймер, независимо от состояния Morph/Glint |
| **Проблеск** | Строго по завершению каждого полного оборота активного проблеска; при выключенном проблеске ударов нет |

Продолжительность удара и послесвечения остаются отдельными параметрами. При синхронизации Morph с TAP/BPM молния читает **фактическую длительность цикла Morph** (BPM, доли на Morph, multiplier), а не пересчитывает ещё одни часы по собственной оценке BPM. В режиме «Проблеск» нет удара сразу после включения: нужен полный оборот.

## Почему раньше не было привязки

В 9.0.5 Lightning использовала только отдельный clock на базе `getSweepTargetVelocity` × частота/множитель × 0.25. Таймер не следил за `Morph.cycleStart` или `Glint.cycleCount`. Кроме того, в `sweepAnimationTick` при включённом Glint выполнялся `continue`, из-за чего Lightning clock мог не обновляться. Это исправлено.
