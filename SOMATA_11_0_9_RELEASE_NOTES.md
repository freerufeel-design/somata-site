# Somata 11.0.9 — Seam-safe Bézier Fillets

## Причина обновления

11.0.8 содержала две независимые проблемы в отображении спиральных контуров:

1. Если у точек спирали имелись сохранённые Bézier-контроли или отдельные касательные, при `roundingFrac > .001` алгоритм мгновенно заменял этот carrier на другой построитель. При идентичной геометрии исходных точек тест зафиксировал отличие контуров около 13 единиц непосредственно у порога .001.
2. После вставки Bézier-скруглений параметр переменной ширины использовал `номер сегмента / количество сегментов` вместо расстояния вдоль спирали. Вставленные скругления меняли ширину не на исходной позиции, а на переразбитом контуре.

Отдельно `blendMorphFilletPaths` в 11.0.8 пересоздавал обе кривые по дискретным точкам и Catmull-переходу; при смешивании близком к нулю исходная кривая могла меняться на фиксированную величину.

## Исправления

- Вспомогательный `blendSpiralCarrierCubics` строит единый контур из исходного и округлённого Bézier-carrier. Параметрические Bézier-участки разделяются алгоритмом де Кастельжо без их геометрического изменения. Станции объединяются по нормализованной длине исходных контуров, поэтому количество кубик может различаться. На границе перехода сохраняется точная исходная геометрия.
- Для спиралей с mapped controls и mapped tangents переход к отображению с округлением происходит непрерывно на интервале от 0 до 12% вместо мгновенного переключения при 0.1%. При нуле исходный линейный/спиральный рендер не затрагивается.
- Та же точная интерполяция используется для переходных отображаемых скруглений `blendMorphFilletPaths` в Polygon/Morph, где ранее пересемплирование вносило собственное отклонение.
- Ширина спирального штриха рассчитывается по накопленной длине уже построенных кривых. Когда сегменты повторяют исходную спираль, сохраняются авторские параметры ширины точек.
- Сокращено количество промежуточных Bézier-сегментов: промежуточный результат содержит только сегменты, необходимые для точного объединения внутренних границ, без избыточной регулярной сетки.

## Без изменений

`js/geometry/unified-fillet.js`, интерполяция Morph, соответствия и позиции исходных точек, фазовые правила, K/N, transport Spiral, исходное отображение при 0%, настройки скругления 0–200%, ограничение падения радиуса (30% по умолчанию), MonoRadius.

## Ограничения

Проверены браузерный Chromium/Canvas2D и вычисление спиральных Bézier-носителей, но не реальный WebGPU пользовательской видеокарты и не конкретный проблемный проект со скриншота. Отсутствие скачков на всех произвольных самопересекающихся контурах математически не доказано; строгая непрерывность кривизны G2 также не гарантируется. Для контуров с более чем 1600 точками в исходном унифицированном построителе остаётся запасной путь: это отдельная зона риска/оптимизации.
