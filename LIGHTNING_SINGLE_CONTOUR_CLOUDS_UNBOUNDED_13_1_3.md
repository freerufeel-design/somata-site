# Somata 13.1.3 — облегчённая молния и настройки облаков

Исходная основа: `Somata_13.1.3_Master_Exact_Parameter_Fix.zip`. Предшествующие исправления Master, Semiramida Glint, FreezeLight, обводки, общего каталога и облаков сохранены.

## Молния

- Оставлен **один геометрический контур** для всех микроимпульсов одного удара: их фазы управляют только прозрачностью (интенсивностью). Не создаются отдельные геометрические копии для соседних импульсов; расчёт ближайшего импульса O(1) вместо перебора всех.
- Для основной WebGPU-ветки Sweep Lightning ядро и ореол объединены **в один растровый проход на кадр** (вместо двух). Для GPU Arc — также один аналитический контурный проход. Остальные эффекты используют прежние ветки.
- Для сложных Graffiti/current-профилей Lightning использует **уже подготовленный центрline/контур**, а не отдельно растеризует широкую Graffiti-ленту. Обычный Glint на профилях не меняется.
- Оба ранее настраиваемых цвета молнии влияют на **постоянный смешанный оттенок контура**; внутри последовательности микроимпульсов цвет не переключается. Можно по-прежнему настраивать яркость и свечения.
- Сохранены длительность удара, частота, число микроимпульсов, размер свечения и точность. Реально геометрия при этом не повторяется для каждого микроимпульса. **Контур всё ещё растеризуется один раз на каждый видимый видеокадр**, а не один раз за весь удар: полное GPU-кэширование кадра между кадрами пока не включено во избежание ошибок на Morph-геометрии.

## Облака

- Поля «Оттенок» и «Множитель оттенка» удалены из интерфейса и общего каталога Blue Morph / Orange Morph / AudioLink: цвет теперь задаёт только палитра «Цвет».
- Для ранее сохранённых настроек ненулевой оттенок **один раз преобразуется в итоговый цвет**, затем устаревшие поля удаляются. Ранее сохранённые *маршруты автоматизации на Hue* больше не поддерживаются и при необходимости должны быть переназначены на цвет.
- «Плотность» и «Скорость» стали полноценными числовыми полями с нижней границей 0 **без верхнего атрибута `max`**. Их множители также принимают неограниченные сверху положительные значения. В регистре Morph и AudioLink сняты ограничения 100 для базовых величин.
- Облака продолжают реагировать на плотность свыше 100, но визуальная непрозрачность естественным образом стремится к 100%: экран не может стать прозрачнее или плотнее физического предела альфа-канала. Количество проходов текстур оставлено ограниченным ради FPS.

## Проверки

- 114 JS-модулей прошли `node --check`; прошли `tests/static-modules.js`, `tests/browser-preflight.js`.
- Прошёл новый `tests/v1313-lightning-single-contour-clouds-unbounded.js` — различные микроимпульсы одного контура, вторичный цвет, выбор одного GPU-прохода, поля без верхнего `max`, маршруты, перенос старого оттенка, плотность 500.
- Прошли браузерные регрессии облаков, FreezeLight, проблеска, Master, Semiramida, общего каталога, случайной обводки и числовых контролов.
- **Ограничение проверки:** на стенде нет рабочего WebGPU; новые GPU-шейдеры проверены синтаксически как часть JS и по структуре исходников, но аппаратный GPU-результат и фактическое изменение FPS не проверены. Работоспособность шейдера на конкретной видеокарте необходимо подтвердить вручную.
