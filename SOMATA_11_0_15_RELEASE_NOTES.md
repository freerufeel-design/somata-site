# Somata 11.0.15 — Continuous Radius Fillets

Цель: исключить проскакивания геометрии скругления на сложных самопересекающихся и зубчатых контурах, не изменяя математическую траекторию Morph.

## Причина

В 11.0.14 максимальный радиус скруглённой фигуры вычислялся при нескольких пробных ширинах, затем по нему выполнялся бинарный поиск. На зубчатых и спиральных контурах максимальный внешний радиус **немонотонен** относительно ширины скругления. Поэтому два соседних значения одного параметра могли выбрать разные допустимые решения с сильно отличающейся шириной.

## Исправление

На исходных вершинах используется строгая консервативная нижняя граница расстояния готовой кривой от начала координат: радиальная составляющая каждой Bézier-коррекции учитывается только если она направлена внутрь. С ростом ширины эта оценка не возрастает. Небольшой линейный запас 4% устраняет плоские участки ограничения, которые иначе могут давать скачки при смене крайней вершины. Теперь двоичный поиск ведётся по строго монотонной оценке, а не по нескольким корням фактического внешнего радиуса.

Общий номинальный радиус сохраняется. При необходимости фактическая ширина **всех** скруглений уменьшается ради соблюдения ограничения максимального уменьшения фигуры. На отдельных сложных фигурах сглаживание может быть консервативнее, чем в предыдущей версии. На обычном квадрате и восьмиугольнике при 30% допуска скругление до 100% совпало с 11.0.14.

## Неизменные части

Не изменены интерполяция Morph, индексы и соответствия вершин, фазы и швы Morph, транспорт и ширина спиралей, флаги скругления, открытые концы, монорадиус и формат пользовательских проектов. Уровни скругления 0–200%, глобальный радиус и параметр ограничения падения радиуса сохранены.

## Ограничения

Проверки не означают математического доказательства G2 для произвольных контуров. Не проверены все пользовательские файлы и аппаратные драйверы WebGPU. Производительность плотной пилы из 5000 узлов может быть недостаточной для 60 FPS на части устройств (локальный замер только построителя — ~86 мс, близко к предыдущему ~84 мс).
