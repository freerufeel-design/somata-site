# Somata 11.0.22 — Signed Radius Witness

**База:** 11.0.21. **Изменённый рабочий файл:** `js/geometry/unified-fillet.js`.

Теперь при срабатывании потенциально дорогостоящего ограничителя радиуса сначала оценивается точная знаковая радиальная потеря в одной внешней точке, с теми же 8 шагами и порядком арифметики, что у полного метода. Если этого достаточно для сохранения допустимого внешнего радиуса, исходный полный перебор можно пропустить. Иначе он остаётся без изменений. Нет зависимости от предыдущего кадра, пороговых переключений геометрической модели или новой интерполяции Morph.

Полный контур, касательные, точки Morph и открытые концы остаются прежними. Это подтверждается строгим сравнением всех числовых команд Bézier с предыдущей версией.

**Ограничения:** доказано только совпадение проверенных геометрий; в конкретном проекте остаются возможны иные источники артефактов. На сверхплотных контурах работа всё ещё может быть медленной. Физический WebGPU не тестировался.
