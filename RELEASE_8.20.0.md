# Somata 8.20.0 — Corridor / Ambients / Refractive Foreground / Test Morph

Дата: 22.10.2026. Основа: Somata 8.19.3.

## Изменения

1. Corridor: `Ширина коридора по глубине` −100…+100%, шаг ползунка 5%, числового поля 1%; 0% воспроизводит прежнюю шкалу копий. Множитель ×1 по умолчанию, диапазон 0…10. Нелинейное распределение сохраняет положение копий на границах и в середине глубины и остаётся монотонным. Встроено в вычисление масштаба копий, Blue/Orange/Audio Parameter Routing и общий каталог (множитель — дочерний параметр).

2. Левая панель «Амбиенты» — розовая амёба. Независимые переключатели дождя (угол, плотность, цвет, прозрачность, скорость, оттенок), дихотомии (2/3 цвета, смещение, интенсивность, оттенок), радужной дихотомии, Рэйацу (интенсивность, скорость), облаков (плотность, цвет, прозрачность, скорость, оттенок). Перенесены существующие органы управления виньеткой. Numeric-параметры (включая оттенки) зарегистрированы в общей Matrix и доступны для Morph и Audio. Основные цветовые пикеры остаются ручными контролами; интерполяция непосредственно между произвольными RGB цветами амбиентов ещё не реализована.

3. Левая панель «Преломление» — яркий череп: линза, куб, череп, додекаэдр и объёмный крест. Управление размером, экранным преломлением, радужной дисперсией, прозрачностью и скоростью вращения; числовые поля маршрутизированы в Matrix. Это **screen-space Canvas compositing** с перспективной 3D-проекцией граней, а не физический 3D-refraction / ray tracing. Дихотомия и дисперсия — стилизованные экранные эффекты.

4. Геометрия → «Анимировать» (выключено по умолчанию). При включении становятся доступны режимы тест-морфа и сдвига, для Spiral — набор спиральных режимов. Длительность перехода по умолчанию 1 с. Тест-морф изменяет исключительно кадр/snapshot перед построением общей геометрии, не меняет параметры сохранённого слоя и не замещает активные Blue/Orange/Green. Это **упрощённые тестовые варианты**, а не численно точные реализации всего внутреннего Blue Morph.

5. Значения Ambients/Refraction включены в проектный snapshot, при открытии проекта восстанавливаются с безопасными настройками по умолчанию.

## Проверка

- `node tests/v8200-ambient-prism-test-morph-corridor-regression.js`: PASS в программном Chromium (без GPU); проверяет контроль Corridor, монотонность curve, наличие Matrix и Audio routes, реальные UI-click, Canvas pixels дождя и пяти форм, а также неизменность authored state при тест-морфе.
- `node tests/static-modules.js`: PASS в ходе разработки до последней косметической правки иконки.
- Из предыдущих версий тесты браузерного Orange могут превышать время работы тестовой оболочки: полного PASS для всего исторического набора нет.

## Ограничения и следующие проверки

- Аппаратный NVIDIA/WebGPU результат и FPS до/после не измерены. Указанные PASS не являются визуальной сертификацией физического GPU-кадра.
- Совпадение математических режимов тест-морфа со всеми настройками Blue не сертифицировано; требуется отдельная интеграция при требовании пиксельной эквивалентности.
- Цветовые пикеры амбиентов и выбор формы призмы сохраняются как enum/color, но Morph/Audio пока управляют числовыми параметрами и углами оттенка, а не произвольной RGB/enum интерполяцией.
- Если отдельное окно вывода Somata использует собственную GPU-композицию, Canvas overlays надо проверять дополнительно в этом окне.
- Повторить реальную многослойную нагрузку Corridor, Morph + Spiral и стресс сочетаний с амбиентами на целевой NVIDIA системе.
