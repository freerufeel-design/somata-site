# Somata 11.0.16 — Mini-edge Safe Radius Guard

Ещё один независимый источник перескоков устранён без изменения формулы движения Morph. На рождении короткого ребра прежний ограничитель внешнего радиуса отдельно суммировал только втягивающие поправки касательных, хотя рядом им соответствовали компенсирующие поправки. Это могло резко уменьшать глобальное скругление при практически неизменном контуре.

Новая оценка учитывает суммарное смещение со знаками, а затем ограничивает только его падение. Таким образом мини-профили могут скрываться под родительским скруглением до фактического роста, а два противоположных вклада не разрушают всю фигуру.

Сохранены радиус 0–200%, настройка допустимого падения 30%, настройка скругления сплайнов, Монорадиус, G1-сопряжения, свободные концы открытых спиралей и все пути линейного Morph. Из исполняемых JS-файлов обновлён только `unified-fillet.js`.

Проверки воспроизводимости и ограничения приведены в `RELEASE_VALIDATION_11_0_16.md`. Этот релиз не гарантирует отсутствия всех аномалий на пользовательских проектах без проверки на реальном WebGPU.
