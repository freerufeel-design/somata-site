# Somata 13.0.2 — лампочки: значения по умолчанию и привязка к скруглённым контурам

Основа: Somata 13.0.1 Optimized. Морфинг опорных точек, движение Circle Slide и математический алгоритм скруглений Somata 13 не изменялись.

- Новые проекты и «Новый»: яркость лампочек **100%**, радиус **30 px × 2** (итог 60 px). HTML-контролы и начальное состояние согласованы. Существующие проекты сохраняют свои записанные значения.
- «Прилипание к линии» теперь использует **настройку каждого слоя** (исправлен прежний баг чтения общей `state.lamps`, в том числе при установке галочки).
- Во время обычного Morph при включенном прилипания выбирается **фактически рисуемая кривая** из FrameContour, включая скругления Somata 13. При несовпадении индексов семантических орбит и рисуемых путей соответствие определяется геометрией **всего исходного пути**, а не ближайшей лампочкой (которая могла перескочить на соседнюю линию при пересечении).
- Для topology/calm опубликованная доля дуги `lampAttachFraction` уже интерполирована из начального и конечного значений по времени морфинга. Она непосредственно определяет точку на соответствующем видимом контуре, без дополнительного сглаживания положения в режиме «Линейный».
- Для circleSlide/topoCircle опорная точка продолжает двигаться по старой траектории; кривая выбирается для **собственной** орбиты, и положение на ней определяется от текущей движущейся точки (то есть зависит от фазы). При GPU-отрисовке лампы остаются GPU-спрайтами, но координаты при включённом прилипании в обычных Morph берутся из реального FrameContour, а не из независимо построенной GPU-кривой.
- Strict Spiral по-прежнему использует специализированные GPU arc-ресурсы без изменений.
- Кеширование таблиц длин для неизменных объектов FrameContour на один кадр избавляет от повторного расчёта одной и той же линии для каждой лампочки.
- В приложение не добавлено ни кнопок, ни диагностического интерфейса. Автотесты существуют только в `tests/`.

## Проверки

- `v1302-lamp-own-rounded-rail-phase-regression.js`: PASS, 14 положений на двух близких перепутанных скруглённых контурах, максимальная ошибка 0; свободная проекция не переносит лампы на соседний путь; отключённая галочка не меняет координаты; сохранённые настройки не сбрасываются.
- `v1302-circle-slide-spline-visible-lamp-regression.js`: PASS, реальный морфинг «По окружности», скругление 125%; 33/33 лампочек на точно отображаемой линии, максимум 1.4e-14 координатных единиц в тестовом Canvas; GPU-shortcut при включённой галочке не подменяет видимый контур.
- Старые тесты Spline / Topology Lamp / GPU привязки: PASS.
- `v1300-preserve-anchor-transport.js`: PASS, 168/168 состояний опорных точек без изменений.
- `v1300-exact-phase-boundary.js`: PASS 24/24 точных стыков, расхождение 0 px. Близкие к стыкам состояния по-прежнему имеют отдельные отклонения (до 5 px), не замаскированы.
- `v1301-reference-raster.js`: 198 снимков обработаны без ошибок.

Ограничения: аппаратная отрисовка WebGPU и FPS на компьютере пользователя не тестировались. В режиме прилипания CPU рассчитывает положение лампочек по видимому контуру; это может стоить дороже GPU-only путей на очень сложных фигурах.
