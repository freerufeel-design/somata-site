# Somata 11.0.19 — проверка стабильности скругления и Morph

## Цель

Уменьшить время построения сложных Bézier-контуров **без изменения видимой геометрии**, линейного Morph, начала/конца фаз и спирального транспорта.

## Изменения

В `js/geometry/unified-fillet.js` входящая и исходящая касательные одного узла рассчитываются совместно, за **один проход по влияющим углам**, а не двумя отдельными проходами. Односторонние производные и опорные точки по-прежнему вычисляются для каждой стороны отдельно; порядок сложения вкладов в каждую производную и координату сохраняется. Удалена ставшая ненужной дублирующая функция вывода одного узла. Другие рабочие JS-файлы не менялись.

Для принудительного обновления ресурсов в `index.html` установлены метки `?v=11.0.19`, заголовок приложения и `manifest.webmanifest` обновлены.

## Производительность

`node tests/v1119-paired-tangent-performance.js` — локальный замер Node.js с прогревом; единица измерения — миллисекунды на построение кривой, **не FPS приложения**.

| Профиль | 11.0.18 | 11.0.19 |
|---|---:|---:|
| Волна, 1000 узлов | 7,24 | 5,12 |
| Окружность, 1000 узлов | 8,76 | 6,25 |
| Волна, 2000 узлов | 25,03 | 16,31 |
| Окружность, 2000 узлов | 32,56 | 21,36 |
| Волна, 5000 узлов | 141,71 | 94,19 |
| Окружность, 5000 узлов | 192,98 | 126,38 |
| Пила, 5000 узлов | 11,49 | 8,94 |

Результаты зависят от формы, процессора, прогрева JIT и настроек ограничителя; в сложных исходных проектах значения могут отличаться.

## Границы подтверждённого результата

Этот релиз **не изменяет кривую 11.0.18**; его преимущество — уменьшение задержки вычисления. Отсутствие новых геометрических скачков подтверждено эквивалентностью команд в проверенных случаях, а не универсальным математическим доказательством. 94–126 мс на 5000 точках всё ещё выше бюджета 60 FPS. Аппаратный WebGPU и конкретный сохранённый проблемный проект не проверены; G2-гладкость произвольных самопересечений не гарантирована.
