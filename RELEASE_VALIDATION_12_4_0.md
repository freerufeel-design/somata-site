# RELEASE VALIDATION — Somata 12.4.0

## Новая функциональность

- Два метода скругления: «Сплайновое» по умолчанию, «Контурное» (прежний построитель 12.3).
- Отдельно остаётся политика радиуса «Обычный / Монорадиус».
- Прямой O(N) Bézier-построитель без вспомогательного разбиения на 8/16 узлов.
- На 0% сохраняется оригинальный профиль. На 0–100% автоматически сглаживаются все стыки, на 100–200% замкнутые контуры плавно приближаются к окружности.
- Новая настройка `layer.roundingShape` хранится в проекте, включена в кэши; смена из UI заблокирована во время Morph.

Новые геометрические тесты: **882** сценария, **16338** проверок G1 соединений, максимальное смещение на почти одинаковых кадрах **7.48e-7** единицы, максимальная радиальная ошибка приближения окружности на 200% **0.1535** при радиусе 100 (включая трёхвершинный профиль).

Браузер: подтверждён реальный UI-переключатель и смена способа построения, сохранение открытого спирального контура, нулевой порог существующего центрипетального сплайна (отклонение управляющей точки **3.65e-8**), native spiral GPU path с **69** сегментами.

Браузерные регрессии старого метода: N4/K2 **24** случая, **8** вариаций настоящей спирали по **21** фазе, **120** проверок касательных.

Местный тест Chromium на **3000** вершин: сплайновый метод примерно **1.8–2.1 мс** против контурного **8.5–9.2 мс** на тестируемом замкнутом контуре. CPU-геометрия, **не** средний FPS.

## Ограничения

Новый сплайновый метод намеренно меняет геометрию (в отличие от эталонной контурной системы), но не траектории Morph. Внешний радиус при 0–100% не контролируется тем же глобальным ограничителем, что и контурный режим; при 200% окружность аппроксимируется сегментами, привязанными к исходным вершинам. На самопересечениях, резких коленах и реальном аппаратном GPU нужны дополнительные испытания. Полное сохранение касательной в крайних вырождениях не гарантируется.
