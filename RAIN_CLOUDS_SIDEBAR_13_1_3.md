# Somata 13.1.3 — FreezeLight Rain / Clouds / Sidebar

Основа: `Somata_13.1.3_Opacity_Catalog_Duplicate_Fixed.zip`. Все предыдущие изменения (единый каталог, Master, Glint, случайная обводка, FreezeLight) сохранены.

## Исправления

- **FreezeLight Rain:** скорость при 100% больше не делает скачок на несколько размеров окна. Смещение ограничивается длиной кадра, а старая история Rain циклически читается через края видимого GPU-буфера. Это устраняет обрезание истории на входящей стороне движения. Обычный FreezeLight не меняет свою логику: для него остаётся прежнее чтение истории без повторения.
- **Облака:** вместо трёх смещённых изображений с пробелами используется непрерывная горизонтальная раскладка с появлением с боков, мягким стыком и двумя перекрывающимися рядами по высоте. При нулевой скорости рисунок стоит, при ненулевой движется. Эффект обрезается границами canvas (видимой области), а не раздвигает страницу.
- **Левая панель:** при сворачивании больше не остаётся пустой 42-пиксельной полосы. Нулевая ширина применяется к панели настроек, но иконки остаются видны. Раскрытие и Easy/Pro сохранены. Мобильный механизм панели не менялся.

## Регрессионные проверки

- `node tests/v1313-rain-clouds-desktop-collapse-browser.js` — браузерное измерение ширины панели до/после, Easy mode, заполнение краёв облаками, анимация и неподвижность при `speed=0`.
- `node tests/v1313-freezelight-rain-viewport-boundary.js` — ограниченная скорость для 320×568, 1032×546 и 1920×1080, проверка изоляции повторного чтения истории только для Rain.
- `node tests/v1313-freezelight-outline-runtime-browser.js` — маршруты AudioLink → FreezeLight и количество случайных слоёв обводки.
- `node tests/v1313-unified-grouped-outline-freezelight.js` — каталог Blue / Orange / Audio и рамки маршрутизации.
- `node tests/mobile-responsive-workspace-regression.js` — мобильная панель, управление параметрами и размеры 320/390/760 px.
- `node --check` — все 114 исходных файлов JavaScript.

**Ограничение:** на тестовом стенде Chrome нет `navigator.gpu`, поэтому непосредственное выполнение WGSL на WebGPU-видеокарте проверить не удалось. Код GPU-перехода проверен статически и математически, а не по настоящему GPU-кадру. Проблемы производительности Morph и заливки SpiroStar из прошлого журнала этим выпуском не решаются.
