# Somata 13.1 — мобильные исправления

Основана на версии `Somata_13.0.26_Mobile_Focus_Two_Row_Fix.zip`.

- Раскрытый список **Слои** больше не сжимается длинной панелью настроек. Список показывает несколько элементов и прокручивается независимо; высота ограничена 42% экрана или 320 CSS px. Основная панель настроек прокручивается отдельно.
- В режиме длительного удержания ползунка скрывается *сам DOM-контейнер* боковой панели, а не только его прозрачность. Это защищает от некорректной отрисовки исходных range-контролов на Android.
- Любые исходные range-инпуты за пределами нижней панели дополнительно скрываются; ползунок в нижней панели остаётся видимым и передаёт `input`/`change` в исходный параметр.
- **Новый проект** скрыт в режиме фокуса, но остаётся в верхней панели вне этого режима.
- У нижней панели убран `backdrop-filter`, чтобы при перемещении ползунка не требовалось размытие анимируемой сцены. Двухстрочный макет сохранён.
- В `index.html` и манифесте версия обновлена до **13.1**; у CSS и JavaScript изменён `?v=` для обновления файлов после публикации без старого кэша.

Проверка: `node tests/mobile-13-1-layers-focus-regression.js`.

Примечание: Chromium проверяет HTML/CSS/JS, но не аппаратную отрисовку WebGPU на телефоне.

## 13.1.1 — мобильный фокус параметров, назначения и профиль

- Длительное нажатие на **название** ползунка открывает двухстрочную нижнюю панель, как и удержание самого ползунка.
- Названия настроек с переключателями, кнопками или списками также поддерживают длительное нажатие: внизу появляется интерактивная копия строки. Изменение передаётся **исходному** элементу и его обработчикам; копия не дублирует ID.
- Если параметр есть в общем перечне параметров Morph, в первой строке рядом с названием появляется кнопка **⇄**. Она открывает существующее меню независимых назначений Blue Morph, Orange Morph и Audio (с выбором слоя или Master). Для не поддерживаемых Morph параметров кнопка не показывается.
- Долгое нажатие на заголовок **«Профиль отрезка»** переносит в нижнее окно *настоящий* редактор с библиотекой, режимами Отрезки/Сплайн/От руки и холстом. Элемент не клонируется: обработчики и холст остаются прежними. При закрытии возвращается на прежнее место.
- Для мобильного popup назначения исправлены высота, позиция и порядок наложения. GPU-сцена остаётся открытой за нижней панелью; исходная панель настроек остаётся скрытой.
- Запросы CSS и JS имеют новый суффикс кэша `?v=13.1.1`, название продукта остаётся **Somata 13.1**.

Проверка: `node tests/mobile-focus-routing-profile-131-regression.js`; также старые тесты мобильных меню, слоёв, фокусировки и Morph. WebGPU на физическом телефоне не проверялся.

## 13.1.3 — числовые счётчики и минимальный поворот по умолчанию

- В геометрии > «Анимация» число «Длительность» использует такую же ступенчатую логарифмическую прокрутку, как остальные временные счётчики. Ограничение 0,1–60 с сохраняется; шаги меняются от масштаба числа.
- Тип слайдинга по умолчанию — **«Минимальный поворот»** в анимации слоя, Blue Morph, начальном состоянии, заводских настройках, сбросе проекта и новых пресетах. При загрузке ранее сохранённого проекта явный выбор «Секторный» и «По фазе» сохраняется.
- Числовое поле разрешено *временно* очищать и вводить промежуточный 0/недопустимый префикс даже при положительном минимуме. Пока ввод неполон, он не передаётся в геометрию. Когда поле становится допустимым, новое число применяется обычным способом. Если оставить поле пустым и выйти, восстановится последнее допустимое значение.
- Колесо мыши изменяет числовой счётчик непосредственно под курсором без необходимости предварительно нажать. Обычные поля используют свой шаг `step`, временные и множители — ступенчатую логарифмическую шкалу; соблюдаются `min`/`max`.
- На смартфоне длительное удержание числового поля (360 мс) с вертикальным перемещением листает значения: **вверх — больше**, **вниз — меньше** (18 CSS px на шаг); короткое касание оставляет обычный ручной ввод.
- Новые проверки: `node tests/mobile-number-counters-1313.js`. Сохранены предыдущие мобильные тесты и геометрия Morph.
- Для обновления браузерного кэша HTML, JS, CSS и манифест используют `?v=13.1.3`. Название приложения в PWA остаётся Somata 13.1.

Проверка выполнена в Chromium без аппаратного GPU; физический Android/WebGPU не тестировался.

## 13.1.2 — компактный профиль и управление точками пальцем

- В мобильном режиме редактор профиля уменьшен до **333 CSS px** при проверке на экране высотой 820 CSS px; максимальная высота ограничена `min(42dvh, 340px)`. Редактор по-прежнему содержит исходный холст и реальные обработчики событий.
- Группы профилей теперь раскрываются кнопкой **«Профили · [группа] ▾»**. Внутри сохранены пять групп и их галочки включения в синий Morph; галочки можно изменять независимо от выбора группы.
- «Отрезки», «Сплайн» и «От руки» имеют три одинаковые колонки. Раздел **«Дополнительные настройки»** сворачивается, а при переходе в «От руки» раскрывается автоматически.
- Для одного пальца: **короткий тап на кривой** добавляет узел на ближайшем участке линии; **движение из узла** перемещает узел; **долгое неподвижное удержание** (570 мс) удаляет узел (минимум два опорных узла сохраняются); **долгое удержание, затем перемещение** меняет прозрачность панели на 20% до отпускания.
- Срабатывание вставки ограничено расстоянием до видимой линии (16 CSS px), попадание в точку — 19 CSS px. В отличие от прежнего двойного щелчка вставка не зависит только от X-координаты и поддерживает формы с обратным ходом.
- «От руки» продолжает пользоваться существующими обработчиками рисования, в том числе сохранением и интерполяцией. Десктопная геометрия и обычная мышиная работа не изменены.
- После закрытия нижнего окна холст, кнопка сброса, вкладки и все дополнительные настройки возвращаются на исходное место без клонирования DOM.
- Новый тест `tests/mobile-profile-touch-compact-1312-regression.js` проверяет настоящие `TouchEvent` в Chromium, размеры 320/390/760 CSS px, вставку/перенос/удаление, удержание с прозрачностью, меню с галочками, режимы Сплайн и От руки и восстановление исходной разметки.
- В `index.html` изменён суффикс кэша CSS/JS на `?v=13.1.2`. Вкладка приложения и PWA по-прежнему называются Somata 13.1.

Проверки проведены в Chromium с отключённым аппаратным GPU. Физический Android/WebGPU требует отдельной проверки.
