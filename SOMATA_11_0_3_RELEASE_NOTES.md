# Somata 11.0.3 — согласование скругления в динамике

## Дефект

При сильном скруглении свыше 100% в промежуточных кадрах Morph могут временно появляться почти развёрнутые углы. Старый механизм защиты петель на 180° вычислял единый коэффициент ограничения для **всей фигуры**. В результате один геометрически проблемный угол обнулял дополнительное скругление на любых других участках. В статике разворота уже нет, поэтому скругление внезапно возвращалось.

## Исправление

`js/app/geometry-gpu-core.js`: `limitHighTurnExtraKnotSmoothing` ослабляет смещение лишь в окрестности высокой кривизны (угол и два его соседних узла), а предел R/2 проверяет отдельно для каждой перемещаемой точки. Это алгоритм визуального построения кривой, не движение опорных точек.

Работает для ручной «Геометрия → Анимация» и тех режимов Morph, где используется общий построитель сильного скругления. В том числе проверены N=8/K=1/R=270, 440.1°, и переходы N=7→8. Противоположные двухточечные орбиты 6/3 по-прежнему не создают петли.

## Границы

Проверено в локальном Chromium с Canvas 2D и отключённым аппаратным GPU. 25 из 25 выбранных регрессионных скриптов завершились успешно. Исторические невыполненные тесты 11.0.2 не переопределялись; полной проверки всех аппаратных платформ нет. Точная сохранённая пользовательская сцена со скриншотов не была предоставлена в формате `.plist`, поэтому проверить каждый её эффект отдельно невозможно.
