# Изоляция методов скругления — 16.4.2b

База — исходная 16.4.2 Skeleton Simple, подтверждённая пользователем. Из 16.4.3 и 16.4.4 изменения не перенесены. Настройки по умолчанию, контроллеры времени, скелет и WGSL не менялись.

## Контракт

- Явный `roundingCornerType: 'simple'` направляет построение к `drawSimpleSpline` / `drawSimplePolyline` с контекстом именно этого слоя. Выбор другого активного слоя с Fourier не подменяет этот метод.
- Simple с отрезками и дискретным профилем использует ломаную 6.7; гладкий профиль — сплайн 6.7. При переходе профилей смешиваются только собственные кривые Simple. При нулевом скруглении сохранена прежняя интерполяция управляющих точек. Прямые замыкающие швы сохранены.
- Общая фазовая коррекция `legacyFilletDrawCorrected` сохранена для согласования концов фаз. Она не является ядром Spline+ и не должна вызывать его при Simple. Для Simple конечные слои получают фактический тип профиля и способ построения сплайна.
- В специализированных построителях спиралей Simple получает свой профиль и явный метод, без изменения существующих ветвей Local, Classic и Fourier.
- Диагностика скачков включается по запросу `SomataJumpTrace.start(...)`, а не постоянно. Предупреждение содержит метод скругления вместо постоянной метки Spline+. Реальные ошибки не фильтруются этой правкой.

## Проверки

`npm test` включает 48 эталонных случаев функций 6.7 и новые тесты `rounding-route-isolation.test.mjs`: 108 конфигураций Local, Classic и Fourier, по восемь кадров, сравниваются с SHA-256 команд чистой 16.4.2. Проверяются три режима морфинга, профили и порядки 0, +1, -1. Также 32 конфигурации Simple на стыках фаз и в середине фазы, расстояния оцениваются по дискретизации кривых. Эти проверки не являются визуальным тестом WebGPU.

Отдельная инструментированная копия использовалась для регистрации входов в математические функции; её трассировочные изменения не включены в сборку. В проверенных 36 конфигурациях Simple (288 кадров) вызовы ядер Spline+ и Fourier не обнаружены. Это не утверждение о всех возможных специализированных маршрутах приложения.

Проверка на реальной видеокарте, произвольных пользовательских проектах и длительная анимация браузера не выполнены. Исходная 16.4.2 остаётся отдельным архивом для отката.
