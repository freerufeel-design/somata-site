# Somata 16.4 — GPU Fourier Lamps (первый этап)

Введён узкий совместный маршрут Line + Lamps. Буфер `vec4(x,y,widthScale,arcLength)` из `fourier-compute.js` используется и индексным штрихом, и вершинным шейдером ламп. `sampleFourierLamp` выполняет двоичный поиск накопленной длины; для замкнутой кривой учитывается последнее ребро. Координаты уже в экранном пространстве: повторное применение матрицы запрещено. Размер лампы сохраняет исходный масштаб.

Спектральный prerequisite записывается и отправляется один раз до обоих потребителей (иначе отложенная композиция может исполняться после ламп). В рабочем маршруте нет mapAsync или GPU → CPU чтения. Скелет и CPU-эталон не менялись.

## Условия

- Статическая геометрия с одним контуром, линия включена, Фурье в области равномерной дискретизации (скругление не ниже 10%).
- Лампы в режиме «Произвольное», привязка к контуру включена, подавление пересечений выключено; не зафиксирован режим движения «Ключевое».
- Без Коридора, FreezeLight/FreezeRain и других потребителей CPU-контура. При несовместимости остаётся прежний маршрут.
- CPU всё ещё строит прежний план ламп, включая эталонный CPU-контур для плотности, координат резервного маршрута и расчёта стабильности. Поэтому это перенос финального размещения, **не устранение CPU Фурье** при включённых лампах. Выигрыш FPS не установлен.
- Морфинг, ключевые лампы, несколько ветвей и Коридор с лампами не переводились. Прежние совместимые режимы 16.3 без ламп сохранены.

## Диагностика

В консоли `window.__spiroLampGPUStatus().webgpu.fourierResident` — счётчик записанных GPU-вызовов отрисовки общего контура. `window.__somataGpuFourierStatus()` — статус вычислительного Фурье. Переключатель `window.__somataGpuFourierEnabled = false` возвращает старый маршрут; `true` восстанавливает автоматический выбор. Для реальной проверки WGSL открыть `http://localhost:8000/app/tools/gpu-fourier-lamps-check.html` и нажать кнопку. Проверка отдельного вычисления спектра: `gpu-fourier-check.html`.

Node-тесты проверяют выбор маршрута, ограничения, структуру привязок и регрессию. Они не исполняют WGSL; визуальная проверка на реальном GPU необходима.
