# Simple Vertex Lifecycle — 16.4.2d

База: 16.4.2c Simple Current Skeleton. Изменён только производственный модуль `js/render/morph-anchor-renderer.js`; индекс, manifest, README и тесты обновлены отдельно. Остальные методы скругления, планировщик движения узлов, GPU, скелет, Коридор и эффекты не менялись.

## Причина

В журнале пользователя за 85,804 с зафиксированы 59 событий TELEPORT (15 в конце фазы до смены serial, 5 при смене serial, 39 внутри фазы), 44 эвристических эпизода SPIKE. На фазе 72 изменение опорной функции составило 82,254 CSS px при прогрессе 0,9999999984894974 → 1. Это не доказывает, что все 44 SPIKE являются дефектами: детектор радиальных выбросов не различает авторский профиль, звезду и ошибку. В журнале отсутствуют полные снимки source/target, а `route: blue-circle-slide` не различает прямой Simple и совместимость.

При разном количестве узлов angular plan содержит повторяющиеся в одном из концов фазы слоты. Пока ребро между ними имеет ненулевую длину, скругление 6.7 ограничивает срез соседнего угла коротким ребром; при удалении совпавшего слота ограничение резко исчезает. Одновременно при обратном обходе плана профиль требуется отразить в системе координат ребра, иначе его конец не соответствует авторской статике.

## Правка

В ограниченном прямом маршруте Simple (одна замкнутая орбита, непрерывный профиль, topology/calm/circleSlide) группы совпадающих в конце фазы соседних слотов определяются из фиксированного плана. Все представления используют только текущие позиции слотов. При малой длине схлопывающегося ребра строится также профиль на объединённой группе, выбирая стабильного представителя. Вклад объединённой топологии плавно зависит от отношения текущей длины ребра к медианной хорде соответствующего конца фазы (переход 2,5–50%, smoothstep); влияние ограничивается половиной фазы у соответствующего конца. При полном объединении исчезающие короткие рёбра не участвуют в видимом контуре. Для промежуточных состояний управляющие точки Simple-кривых смешиваются после точного разбиения на общие интервалы. Это геометрическая интерполяция двух представлений текущего транспорта, не задержка и не фильтрация кадров. Сам план/скелет не модифицируется. При обратном обходе `srcReversed`/`dstReversed` применено отражение авторского профиля на соответствующем конце.

Формулы Simple, Spline+ и Fourier не изменены. Общий legacyFilletDrawCorrected в прямом Simple по-прежнему не вызывается. Для многоорбитных, разорванных и открытых профилей, спиралей, chaos, monoradius сохранена совместимость 16.4.2c. Это ограниченный шаг, а не полное решение всех острых выбросов.
