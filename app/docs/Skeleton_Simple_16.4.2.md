# Somata 16.4.2 — Skeleton & Simple

База: 16.4.1 Fourier Continuity. Две независимые правки.

## Blue: направляющие

`blueSharedSkeletonFrame()` преднамеренно сохраняет совместимый маршрут округлённых многоугольников `blue-anchor-linear` / `blue-circle-slide`, чтобы не нарушать переходы между точными конечными контурами. Ранее `skeleton-debug-overlay.framePaths()` возвращал пустой массив при отсутствии опубликованного скелета. Теперь при таком Blue-маршруте направляющие вычисляются по фазовым опорам текущих исходного и целевого слоёв, через `SomataMorphRuntime.sampleSkeleton`. Готовый контур не читается. Опубликованный первичный граф, если он есть, приоритетен. Сброс провайдера очищает и его поля скелета, чтобы не читать данные прошлой фазы.

Старый маршрут линии не перестроен: независимый опорный граф не означает доказанную полную унификацию старого рендера линии. Orange/Green/Lightning не переносились. Проверены 12 последовательных пар фаз, по 5 значений фазы, и приоритет опубликованного графа; это тест подготовки данных, а не длительный браузерный прогон.

## Простой (6.7)

В интерфейсе самостоятельные методы «Простой (6.7)» и «Фурье» вынесены из группы Spline+. Spline+ содержит только локальный и классический методы. Все варианты взаимоисключающие, сохранён прежний ключ `roundingCornerType: 'simple'`, миграция проектов не требуется.

Простой метод использует `drawSimplePolyline` для отрезков/дискретного профиля и `drawSimpleSpline` для гладкого сплайна. Прямой диспетчер больше не выбирает геометрию Spline+ при нулевом скруглении. Дискретный полигональный сплайн семплируется в пространстве профиля, как в 6.7. Спиральная математика и GPU Фурье не изменены. В 6.7 применялись квадратичные угловые соединения для ломаной и отдельные касательные кубические соединения для гладких локальных сплайнов. Не заменяем их формулами Spline+.

`tests/simple-rounding-6.7-golden.json` — команды исходного HTML 6.7 (извлечены его функции `roundPolylineForDraw` и `splinePathForDraw` с их зависимостями, без Fourier). 48 случаев: открытый/замкнутый, с/без отмеченных углов, 0/1/65/100/165/200%. Проверка чисел с допуском 1e-9. Это эталон алгоритмов скругления, не пиксельное сравнение целого приложения 6.7.

Визуальное исполнение WebGPU не проверено в этой среде.
