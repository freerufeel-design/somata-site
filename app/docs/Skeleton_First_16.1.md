# Somata 16.1 — Skeleton First / исправление направляющих

База: Somata_16.1_GPU_Geometry_Guides.zip. Формат проекта и номер версии 16.1 не менялись.

## Интерфейс

В `js/ui/color-picker.js` глобальный capture-обработчик `contextmenu` раньше обработчика `btnGeometryGuides` находил соседний цветовой input в `.floating-display-controls` и останавливал событие. Теперь кнопка направляющих и нецветовые элементы её меню исключены из поиска цвета. Настоящие цветовые input, в том числе внутри меню, по-прежнему открывают палитру. ЛКМ и клавиатурное управление направляющими не изменены.

## Направление зависимостей

Целевой контракт: морфинг и сопоставление опор → скелет → порядок спирали → профиль/скругление → пути кадра → Коридор → эффекты → WebGPU.

Статический `buildOrbitPolylinesScoped` строит `createGraph` до профиля; основные неплоские профили используют `edgeSamples`. Исправлены два коротких маршрута: плоский контур читает `graph.nodes` (без общей ссылки на узлы), продолженные линии читают `graph.edgeSamples`, а не исходное кольцо опор. Для совместимых плоских carriers без graph сохранён прежний маршрут по их собственным точкам скелета. Не менялись формулы спирали, скругления, швы, фаза морфинга, трансформации Коридора или формат сохранения.

`SomataMorphRuntime.samplePrimary` сначала получает `skeletonAt`, затем строит профиль из этого кадра, публикуя `skeletonFrame` рядом с `framePaths`. Исправлен отсутствовавший импорт `signedAngleDelta` в `geometry/morph-math.js`, выявленный новым тестом реального ES-модуля.

Граф в статической диагностике берётся из метаданных, прикреплённых при построении путей; он не восстанавливается из контура. В отдельных совместимых маршрутах Orange, Green, Lightning и некоторых GPU-морфах общий авторитетный skeletonFrame ещё не гарантирован. Полная унификация не проводилась. Не утверждается, что все специальные пути следуют единому VisualCarrier.

## Проверка

Новые тесты: `geometry-guides-context.test.cjs`, `skeleton-source-of-truth.test.mjs`.
Проверки: маршрутизация ПКМ, сохранение цветовых контролов, движущиеся узлы вместо исходных опор, отсутствие изменения скелета при правке контура, продолжения по фактическому ребру, независимость статического графа от профиля/скругления/касательного смешивания, совпадение основного морфинга и независимого расчёта скелета (7 режимов × 3 порядка × 2 источника × 3 фазы).

Полноценный браузерный запуск не выполнен: Chromium в среде проверки заблокировал локальный адрес (`ERR_BLOCKED_BY_ADMINISTRATOR`). Проверка реального WebGPU и производительности не выполнена.

Итоговый прогон: 122/122 тестов (33 файла); эталон 3024 статических конфигураций совпадает.
