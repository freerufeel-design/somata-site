# Монитор геометрии 16.4.2f

Автоматически активен после загрузки. Проверяет выбранный слой в морфинге со скруглением > 0 и видимой линией. Использует уже записанные CPU-команды линии (или готовый FrameContour), не вызывает построение линии повторно, не сохраняет новый контур в кадре и не читает GPU. Скругление, профиль, скелет, фаза и рендер не изменяются монитором. Открытые контуры, Коридор, кадры без подходящих CPU-данных пропускаются. Смена слоя, режима или скругления сбрасывает сравнение соседних кадров.

- `SPIKE`: кандидат на острую выступающую вершину; угол поворота от 30°, локальное превышение медианного радиуса других радиальных максимумов от 3 px и 3%.
- `TELEPORT`: кандидат на скачок формы от 3 CSS px по 48 опорным направлениям, с резким изменением движения.
- `PHASE TELEPORT`: скачок от 3 px при смене номера фазы или почти неизменном прогрессе около 0/1. Это включает скачок в самом последнем кадре старой фазы.

Каждое событие содержит слой, фазу, прогресс, метод, N/K, скругление, маршрут. Скачки содержат измеренное движение, импульс, предыдущее состояние. Повторы группируются до трёх чистых кадров; переход фазы может создать отдельное событие. Журнал: до 1000 событий в памяти; встроенная консоль сохраняет собственный лимит записей. Пороговые события не являются доказательством ошибки: намеренный острый профиль, меняющийся радиус, сложные звёздчатые контуры и обычное ускорение могут вызывать срабатывания. Опорная функция не обнаруживает все внутренние деформации вогнутых фигур. Измерение выполняется на CPU-контурах, а не по пикселям экрана. Монитор добавляет CPU-нагрузку, особенно на сложных фигурах; фактический FPS не измерялся.

В консоли браузера:

```js
SomataGeometryMonitor.start()   // сбросить статистику и начать новый замер
SomataGeometryMonitor.summary() // числа без полного журнала
SomataGeometryMonitor.report()  // полный журнал (последние 1000 событий)
SomataGeometryMonitor.stop()    // отключить проверку, вывести итог
```

Во встроенной консоли программы (клик по FPS на десктопе) предупреждения имеют метку `geometry.monitor`; прочие ошибки и прежний механизм SomataJumpTrace сохранены. Выбор метода и монорадиуса использует прежние обработчики изменения состояния. Монорадиус по-прежнему скрыт при Fourier, где не применяется. Стрелки обходят четыре метода циклически.
