# Somata 13.1.3 — Master: единая запись параметров во все слои

## Что исправлено

- Запись из настройки активного слоя распространяется на все физические слои **до завершения события** ввода/изменения/нажатия, а не только после двух микрозадач. Исправляет задержку распространения Glow, интенсивности и множителей, толщины линии и других параметров.
- Повторная установка текущего значения активного слоя теперь тоже назначает его остальным слоям. Используется единый программный определитель путей параметров (обычные поля, вложенные конфигурации, кнопки и семантические исключения). Например, Glow `9 / 1 / 4` после выбора `9` становится `9 / 9 / 9`.
- Отдельные параметры настроек `sweep`, `web`, `particles`, `lamps`, `sprite`, `lineMotionFx` и геометрии теперь поддерживают такую же семантику даже при повторном выборе значения.
- Комбинированные кнопки режима линии (Точка / Штрих / Sprite / Graffiti), профиля и ламп больше не откатывают изменения связанных полей, которые уже были записаны их физическими обработчиками во все слои.
- Включение Проблеска/Молнии вычисляет итоговый `sweep.enabled` индивидуально для каждого слоя, с учётом другого переключателя: не копирует слепо итоговый флаг с активного слоя.
- Все затронутые слои получают уведомления о смене свойств для рендеринга. Обновляются живые слепки Blue Morph для изменённых полей, включая правки редактора профиля.
- Действия элементов, останавливающих распространение события, сохраняют отложенное резервное применение; обычные события применяются синхронно в фазе всплытия на `window`.
- Режим Master не смешивает все настройки в момент включения: индивидуальные отличия сохраняются до явного изменения конкретной настройки.

## Инварианты

- Master записывает параметры **слоя** во все слои; проектные настройки общего уровня по-прежнему остаются общими. Идентификаторы, имена и флаг видимости слоёв не нормализуются автоматически при правке параметров.
- Цвет RGB заливки и её прозрачность обрабатываются по отдельности; изменения одного аспекта не перезаписывают другой на соседних слоях.
- При выключенном Master редактирование активного слоя остаётся независимым.

```bash
node tests/v1313-master-control-paths.js
node tests/v1313-master-all-layer-controls-browser.js
node tests/v1264-master-live-rounding-browser.js
node tests/mobile-number-counters-1313.js
node tests/mobile-13-1-layers-focus-regression.js
node tests/static-modules.js
```

Проверены три слоя, синхронная установка значения и повторный выбор без изменения исходного значения, вложенные эффекты, режимы линии, индивидуальный RGB заливки, Blue Morph, смена активного слоя и выключение Master.

Примечание: общий старый файл `tests/contracts.js` имеет две уже существующие неуспешные проверки Spiral/Corridor, которые воспроизводятся также на нетронутом архиве 13.1.3 и не относятся к Master.
