# Somata 11.0.7 — протокол проверок

Все пункты ниже проверены на предоставленном архиве 11.0.6 с заменённым только построителем скруглений. В состоянии проекта из пользовательского скриншота фактические значения всех профилей неизвестны.

| `node tests/v1106-fillet-phase-stability-regression.js` | PASS | 351 фазовое сравнение; проверки шва и открытой спирали |
| `node tests/v1105-unified-fillet-overlay-regression.js` | PASS | 900 случайных профилей, скругление до 200%, ограничение внешнего радиуса |
| `node tests/v1107-k2-spiral-phase-browser-regression.js` | PASS | 24 браузерных сценария: N=4, K=2, угол 167°, 40/100/150/200%, Segments/Spline и три режима транспортировки, точные начала и окончания фаз |
