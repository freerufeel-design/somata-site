# Somata 12.1.0 — отчёт о тестировании

## Цель и безопасность

Проверить вариант **8 вместо 16 вспомогательных отсчётов** для каждого сплайнового ребра без изменения Morph, соответствия вершин и спирального транспорта.

**Решение:** не включать уменьшение разбиения по умолчанию, поскольку это заметно меняет форму на отдельных острых профилях. Оставить 16 базовым режимом; экспериментальные 8 — только явно выбранный режим, общий для всей сессии. Переключение в активном Morph заблокировано, чтобы не было нового фазового скачка.

## Браузерное сравнение фактической линии (Chromium, Canvas2D)

На 48 сценариях (окружность, волна, звезда, открытая спираль; 7/15/30 исходных вершин; скругление 15/70/140/200%):

- Bézier-сегментов при 16 шагах: **14 752** суммарно.
- Bézier-сегментов при 8 шагах: **8 192** суммарно (**−44,5%**).
- **96** сравнений при смещении вершин на ~1e−6 единицы: **0 значимых несовпадающих пикселей за пределами радиуса 2 px**, то есть новый скачок при таком малом движении не обнаружен.
- Результат **НЕ является точным совпадением кривых 8 и 16**. На одном тесте звезды из 15 вершин при скруглении 200% было **837** пикселей, не имевших соответствия в радиусе 2 px. На открытой спирали из 7 вершин при 200% — 440. Эта разница слишком велика, чтобы сделать 8 новым стандартом без согласования формы.
- Замеры времени для волны из 200 точек нестабильны: в одном запуске 8 шагов ~3,7 мс и 16 шагов ~4,9 мс, в другом ~6,2 мс против ~5,0 мс. Поэтому гарантированный рост FPS **не подтверждён**; профилировать нужно на целевом оборудовании.

## Сохранность исходной геометрии

`node tests/v1210-spline-density-baseline-equivalence.js`: **224 сценария** с исходным, включённым в тесты кодом Somata 12.0.0 дают **идентичные Bézier-команды** при выборе 16 шагов, включая мини-рёбра, открытые/замкнутые профили и скругление в диапазоне 0–200%.

`node tests/v1210-spline-quality-ui-browser.js`: проверены исходные 16, ручное включение 8, возврат на 16 и блокировка смены качества во время Morph.

`node tests/v1210-spline-density-browser-regression.js`: 48 сравнений видимой кривой 8/16 и 96 соседних кадров.
