# Somata 13.0.19 — фиксированный номер фигуры фокуса

Основа: полная Somata 13.0.18 со всеми прежними возможностями.

## Что изменено

- Фокус Spiral/Corridor указывается **целым номером фигуры** от 1 до текущего общего количества; вместо процентов отображается «№7» и т. д.
- По умолчанию номер фокуса **7** (автоматический режим). При включении «Ручной фокус» можно выбрать конкретный номер шкалой с шагом 1.
- Фокус вращения и фокус подсветки рассчитываются из одного абсолютного физического номера, а не из 66% от меняющегося количества фигур. Когда количество меняется с 8 на 9 при выборе №7, положение углового фокуса не меняется, а значит не происходит прежнего мгновенного поворота всех спиральных копий.
- Максимум обоих ползунков обновляется по числу фигур, отображаемому счётчиком Corridor; учитываются скрытые центральные и внешние фигуры. Самый дальний экземпляр тоже выбирается.
- Если в текущем кадре фигур меньше выбранного номера, фактически используется последняя доступная. Желаемый номер в настройке сохраняется и восстанавливается, когда фигур снова достаточно.
- Настройка сохраняется как новое целое `spiralRotationFocusFigure`; старый процент `spiralRotationFocusPercent` из прежних проектов **не интерпретируется как номер**. Проекты без нового параметра получают значение 7. Маршрутизация Morph использует новый параметр `spiral.focusFigure`; старые автоматизации процента нужно перенастроить.
