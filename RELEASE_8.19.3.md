# Somata 8.19.3 — Strict Orange Parameter Routing & Matrix Visual Parity

Основа: Somata 8.19.2; исправления производительности 8.19.1 и синхронизации палитр 8.19.2 сохранены.

## Поведение Orange Morph

- Каждая новая Orange-композиция сначала строится как набор возможных значений, а затем собирается из **сохранённых настроек текущих слоёв**. Применяются **только параметры, реально включённые в матрице Orange**, с учётом процента охвата слоёв. Значения для выключенных/удалённых строк не меняются.
- Ключи, отсутствующие в матрице (настройки Web, Lamps, Sweep, Graffiti, Particles, анимация, видимость, Fill и т. д.), теперь **не перезаписываются рецептом**. Это относится и к стандартным, и к готовым тематическим Orange-профилям, и к генерации кнопкой Dice, и к циклам активного Orange Morph.
- Специальные маршруты «Форма», «Орбиты», «Хаос», «Спиральные слои» применяются только при их явном включении, также с учётом «Слои %». Геометрия N/K, вращение, размеры, эффекты, цвета и прозрачность независимы друг от друга.
- Заполненная матрица остаётся по умолчанию для нового проекта. **Намеренно пустая матрица в сохранённом профиле не заполняется скрытыми параметрами** при загрузке, переключении, сохранении либо сбросе. Из сохранённого минимального профиля применяются только известные настройки редактора Orange; неизвестные поля не попадают в состояние проекта.
- Автоматическое переключение общей палитры Orange выполняется только при наличии активного цветового маршрута. Синхронизация палитр Blue/Orange из 8.19.2 сохранена.
- При изменении только цвета заливки непрописанная прозрачность остаётся прежней; маршрут непрозрачности применяется независимо от положения строки в матрице.
- Изменение числа слоёв из заголовка Orange остаётся явной настройкой. Если создаются дополнительные слои, их исходное состояние копируется из существующих слоёв, а затем применяется только явный набор маршрутов.

**Изменение семантики старых тематических Orange-профилей:** рецепты больше не могут включать Lamps, Web или Fill или отключать анимации как побочный эффект стилистического выбора, если соответствующие настройки не выбраны для морфинга. Чтобы получить старый рецепт с дополнительными эффектами, включите их явно на исходных слоях либо добавьте соответствующие параметры в матрицу.

## Интерфейс

- Строки «Форма» и «Орбиты» в Blue и Orange имеют те же фон, рамку, скругление и типографику названия параметра, что обычные строки.
- Настройка диапазона орбит в процентах и выбор наборов профилей формы не изменены.

## Проверки

- Проверка синтаксиса 103 production JavaScript-файлов (Node `--check`).
- `tests/v8193-orange-explicit-routes-regression.js`: генерация Dice, активный Orange Morph, пустая матрица, только толщина линии, доля 0%, сохранение/переключение профиля, запрет неизвестных полей.
- `tests/v8193-orange-special-row-style-regression.js`: реальные вычисленные CSS-стили в Chromium для четырёх специальных строк.
- `tests/v8192-morph-palette-allocation-sync-regression.js`: палитры и синхронизация.
- `tests/v71116-orange-routing-palette-stop-corridor-regression.js`: Corridor Palette Lag.
- `tests/v71115-orange-header-orbit-percent-regression.js`: проценты орбит.
- `tests/v7110-orange-shared-routing-lifecycle-regression.js`, `tests/v7107-orange-static-generation-presets-regression.js`: актуализированы ожидания для явных маршрутов.

Графические проверки проводились в headless Chromium без аппаратного GPU. Производительность и все визуальные комбинации эффектов требуют проверки на целевом железе.
