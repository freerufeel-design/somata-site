# Somata 8.20.6 — видимая WebGPU-сфера, стартовый 3D и иконки амбиентов

База: Somata 8.20.5. Сохранены остальные функции Blue/Orange/Green, Corridor, Ambient/2D Sprite, множители и маршрутизация параметров.

## Исправления

1. Новые проекты: `state.prism.enabled = false`, `state.prism.mode = '3d'`, `state.prism.shape = 'sphere'`. В новой панели по умолчанию выбран `3D · Оптика`. При загрузке сохранённого 2D-режима выбор пользователя сохраняется. Legacy-проекты с Prism без поля `mode` переводятся в исторический 2D-режим.
2. 3D-слой не должен пропадать, если WebGPU не может загрузить фон из `finalGpuCanvas`. Создан Canvas2D-мост для копирования сцены в текстуру. По возможности используется фактическая финальная сцена, затем альтернативные существующие Canvas. При ошибке GPU-upload сферу продолжает отрисовывать настоящий GPU-pass, с запасной фоновой текстурой. Ошибка фона сохраняется в `SomataPrism3D.status().sceneError`.
3. Повышена читаемость материала стекла: Fresnel-подсветка краёв, усиленные блики и объём. В основном WebGPU/WGSL шейдере остаются сферическая рефракция и RGB-дисперсия при доступном снимке фона.
4. Если оптический WGSL-шейдер не может скомпилироваться, отдельный *упрощённый WebGPU glass shader* может отрисовать именно трёхмерную геометрию. Он **не** обещает рефракцию: в статусе появляется `opticalReady:false` и причина `opticalError`. Никакой 2D Canvas-имитации в режиме 3D не используется.
5. На верхней части панели доступен короткий статус 3D: выключено / подготовка / 3D отрисовано / упрощённый WebGPU / ошибка.
6. Иконки левой панели: череп выключен — серый, включен — светящийся белый; амёба выключена — серая, включена — розовая. Желтая рамка активной панели для черепа удалена. Состояние эффекта, а не факт открытия панели, определяет подсветку. Контекстное меню (ПКМ) переключает эффект как раньше, чекбоксы обновляют состояние иконок.

## Тесты

- `node tests/v8205-webgpu-optics-modes-regression.js`: нормальный WebGPU-путь шести фигур, реальная передача сцены через Canvas2D-мост (mock device), отказ GPU-copy не скрывает фигуру; 7 GPU-submit.
- `node tests/v8206-basic-glass-when-optics-fails-regression.js`: принудительный compile error оптического WGSL, базовый WebGPU shader формирует draw/submit, фигура остаётся видимой.
- `node tests/v8206-glass-sphere-visibility-and-icons-regression.js`: иконки, стартовые настройки, пути GPU и диагностика.
- `node tests/v8205-ui-mode-browser-regression.js`: поведение 2D/3D и default в Chromium.
- `node tests/v8204-real-ui-multipliers-contextmenu-regression.js`: управление ПКМ, Blue, множители в Chromium.
- `node tests/v8203-independent-3d-and-corridor-glint-regression.js`: геометрия сеток и передача проблеска в 12 копий (не аппаратная проверка).

## Что остаётся на аппаратную проверку

- Итоговое появление стеклянной сферы на NVIDIA/драйвере пользователя, поверх финальной 2D/GPU-сцены.
- Физические пиксели: искривление линий внутри стекла, заметная хроматическая дисперсия, частота кадров и корректная композиция при Corridor.
- Надёжность `drawImage(finalGpuCanvas)` и WebGPU canvas capture зависит от браузера. В случае недоступности фона фигура остаётся видимой, а оптика/дисперсия фона могут не работать. В статусе это различается.

**Важно:** команды/моки и браузерная проверка интерфейса — не сертификат аппаратного WebGPU. Реалистичная трассировка лучей для многогранников в этот выпуск не включена.
