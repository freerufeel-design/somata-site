# Somata 8.20.7 — возвращение реальной оптики в WebGPU 3D

База: Somata 8.20.6. Минимальное исправление WGSL-шейдера; Blue / Orange / Green, Corridor, Ambients, 2D Sprite, матрица параметров и сохранение проекта не менялись.

## Почему стекло не работало

Пользовательский GPU-лог NVIDIA: `Somata optical 3D shader: 58:11 '@builtin(position)' appears multiple times as pipeline input`.

В `js/app/prism-3d-layer.js` фрагментный шейдер объявлял `@builtin(position)` **одновременно** в `VertexOutput.clipPosition` и отдельном параметре `frag`. Поэтому WebGPU отвергал **весь оптический pipeline**, и приложение использовало резервный непрозрачный синий шейдер (`opticalReady:false`). Сфера/куб появлялись, но не могли ни преломлять, ни разделять цвет лучей.

## Что исправлено

- У фрагментного входа остался **ровно один** `@builtin(position)` через `VertexOutput`.
- Прямая выборка пикселя фоновой сцены при нулевой рефракции теперь использует `input.clipPosition.xy / u.viewport.xy` (в fragment stage это координаты пикселя, а не clip-space).
- Основная WebGPU-оптика использует фоновую сцену из текстуры и двухповерхностное преломление сферы (Snell); RGB-каналы считываются по разным направлениям для дисперсии.
- Резервный непрозрачный материал сохранён **только** для реального отказа основного shader/pipeline; он не должен включаться из-за прежнего двойного атрибута.
- Версия ссылок ресурсов в `index.html` обновлена на `8.20.7`, чтобы браузер не сохранял старый дефектный shader JS из кэша.

- `node tests/v8206-basic-glass-when-optics-fails-regression.js` — PASS. Искусственный отказ оптики не ломает базовый WebGPU-pass.
- `node tests/v8205-webgpu-optics-modes-regression.js` — PASS. Проверка шести 3D mesh, загрузки сцены и отказа GPU-copy.
- `node tests/v8206-glass-sphere-visibility-and-icons-regression.js` — PASS.

- `node tests/v8203-independent-3d-and-corridor-glint-regression.js` — PASS.
- 107 production JS — синтаксис PASS.

**Граница проверки:** браузер Chromium в доступной среде блокировал навигацию к тестовой странице; реальный WGSL-компилятор и аппаратное WebGPU-изображение NVIDIA здесь не подтверждены. Успешная проверка mock GPU **не** равна аппаратной пиксельной сертификации. Если `opticalReady` всё ещё `false`, диагностическое поле покажет новое сообщение компилятора; если `sceneUploaded` равно `false`, нужно отдельно разбирать получение снимка 2D-сцены.

## Проверка вручную

1. Открыть новую сборку с очищенным кэшем / обновлённым `index.html`.
2. На вкладке `3D · Оптика` включить `Сфера`, поставить рефракцию и дисперсию выше нуля.
3. Поместить за сферу линии и вложенные копии Corridor. При исправной оптике они должны менять положение внутри её силуэта и иметь цветовое расщепление на кромках.
4. В статусе 3D должно быть «WebGPU 3D: фигура отрисована…» **без** красного сообщения «оптика недоступна»; если красное сообщение осталось — прислать его целиком.
