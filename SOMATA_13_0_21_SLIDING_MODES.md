# Somata 13.0.21 — режимы слайдинга спирали

## Пункт «Слайдинг спирали» (в Blue Morph и тестовом редакторе)

1. **Неразрывный — фикс N/K** (`continuous`): случайное изменение N и K отключается, меняются разрешённые геометрические характеристики.
2. **Неразрывный — без фикса N/K (клонирование)** (`phaseCircle`): N/K могут меняться; действует непрерывный спиральный перенос и существующее сопоставление ветвей с появлением/угасанием копий.
3. **Фейд** (`fadeSpiral`): каждая исходная ветвь плавно растворяется, каждая целевая плавно проявляется. Они рисуются в собственных конечных координатах; ни одна из них не интерполируется через несоответствующую геометрию. Фейд спирали работает внутри Blue Morph «По окружности», без необходимости переключать общий тип морфинга.
4. **Рваный** (`torn`): сохранено прежнее соответствие по минимальному углу с точным разбиением Bézier.

«НФО без клонирования» удалено из вариантов выбора. Проекты предыдущих сборок с режимами `phase` и `minimalTurn` остаются читаемыми, а сохранённые `nfoNoClone` переключаются на `phaseCircle`, чтобы исключить экспериментальную математику.

Исправление фокуса №7 из 13.0.19 сохранено. Спиральный фейд намеренно не является геометрически неразрывным переходом.
