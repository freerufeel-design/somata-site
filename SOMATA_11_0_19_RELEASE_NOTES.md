# Somata 11.0.19 — Paired-Tangent Fillets

Стабилизация времени построения кадра, без изменения геометрии скругления и линейного Morph. Совместное вычисление касательных одного Bézier-узла уменьшает повторную работу при перекрытии скруглений на волнах, окружностях и плотных спиралях. 615 точных сравнений команд с 11.0.18 пройдены; браузерные проверки Static/Morph и спиралей также пройдены.

Сохранены общий радиус скругления 0–200%, лимит потери внешнего радиуса 30% по умолчанию, Монорадиус, неподвижные концы открытых линий, G1-сопряжения и прежняя фазовая логика. Неизменный линейный Morph остаётся эталоном. Документ `RELEASE_VALIDATION_11_0_19.md` содержит детали и команды запуска.
