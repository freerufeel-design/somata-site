# Somata 11.0.20 — проверки стабильности скруглений

## Объём изменения

Основа: архив `Somata_11.0.19_Paired_Tangent_Fillets.zip`.
Из исполняемых JavaScript-файлов изменён только `js/geometry/unified-fillet.js`.
Изменения касаются **исключительно обхода уже существующих Bézier-событий** при расчёте двух касательных в каждой точке. Математика кривых, формулы влияния, порядок сложения вкладов, параметры ограничителя радиуса, координаты и соответствие вершин, N/K, часы фаз, MonoRadius и транспорт спиралей не изменялись. `index.html` и манифест также обновлены для загрузки новых ресурсов.

### Новый алгоритм

В 11.0.19 для каждого отсортированного Bézier-узла выполнялся отдельный двоичный поиск первого активного угла и последовательный просмотр событий до его правой границы.
В 11.0.20 обе границы окна сдвигаются **только вперёд** вместе с отсортированными узлами. Из активного окна события суммируются в исходном порядке; точки и входящие/выходящие производные рассчитываются исходными формулами. Финальная ширина поддержки `width * factor` для каждого события вычисляется один раз **после** ограничения радиуса. Нет изменения геометрии и нет зависимости от предыдущего кадра — построитель остаётся детерминированным.

## Быстродействие

Для повторения: `node tests/v1120-ordered-knot-benchmark.js` — медиана 9 измерений после 3 прогревов, Node.js, **не FPS всей программы**.

В одном из локальных прогонов на фигурах по 5000 точек:

| Профиль | 11.0.19 | 11.0.20 |
|---|---:|---:|
| Волна | 108,19 мс | 91,97 мс |
| Окружность | 143,96 мс | 123,06 мс |
| Пила | 8,18 мс | 7,36 мс |

В повторных прогонах разница была менее стабильна, а на некоторых небольших контурах 11.0.20 была немного медленнее: оптимизация **не гарантирует** ускорение в каждой сцене.

## Ограничения

11.0.20 **не меняет** видимую кривую 11.0.19 и потому сама по себе не исправляет геометрический дефект, который ещё не был воспроизведён на конкретном пользовательском проекте. Ускорение призвано уменьшить вычислительную задержку сложных кадров. 5000-узловые контуры всё ещё превышают бюджет 16,7 мс для 60 FPS. Реальный аппаратный WebGPU и проект со скриншота недоступны; G2 для произвольных самопересечений не гарантируется.
