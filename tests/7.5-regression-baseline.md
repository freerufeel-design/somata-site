# Somata 7.5 regression baseline

The four 7.5 field regressions were created and executed against the clean `Somata_7.4.30.zip` before the runtime fixes. All four exited non-zero, so they reproduce behavior that was not protected by the previous green gate.

| Regression | Clean 7.4.30 | 7.5 contract |
| --- | --- | --- |
| `v75-effect-stack-order.js` | FAIL | Web must be below Line/Graffiti, then Lamps, Glint/Lightning, Particles. |
| `v75-web-bezier-contour.js` | FAIL | Web visual contour must come from retained cubic Bézier truth, not the independent rounded path. |
| `v75-lightning-performance.js` | FAIL | Exact Lightning must use balanced 4× raster and analytic halos without the legacy blur dependency. |
| `v75-checkbox-functional-coverage.js` | FAIL | Every settings checkbox must have observable behavior; the Legacy no-op `lineSpriteEnabled` control is not allowed. |

The final 7.5 gate keeps these regressions in `tests/run-all.js`; `stability-soak.js` also repeats the Web, Lightning and checkbox checks in fresh browsers.

Hardware note: local/headless Chromium proves UI → state → geometry/effect preparation → GPU-bound queue/commands → scheduler liveness, but it cannot certify physical WebGPU pixels or real monitor FPS. A real GPU visual/FPS result overrides the headless inference and should become the next regression test if it disagrees.
