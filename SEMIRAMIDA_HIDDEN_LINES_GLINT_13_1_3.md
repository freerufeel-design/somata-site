# Somata 13.1.3 — проблеск на всех слоях при скрытых линиях (Semiramida)

## Воспроизводимый проект

Пользовательский `default.plist` — JSON-плейлист формата `SpiroStarPlaylist`, версия 5. В нём найден проект «6 Semiramida», содержащий три видимых слоя:

1. `Внешний каркас 1` (`layer_1790298334855_udz9i8`)
2. `Средний орнамент 2` (`layer_1790298334855_s9iv09`)
3. `Внутренний акцент 3` (`layer_1790298334855_67p77j`)

В сохранённом проекте `sweep.glintEnabled=true` у всех трёх слоёв. При скрытии `lineVisible` на всех слоях проблеск не должен отключаться. Подготовка кадров в браузере подтверждает, что геометрия Glint остаётся непустой (1, 2 и 1 контур), а граф рендеринга содержит Sweep у каждого слоя.

## Исправление

В `js/render/main-pipeline.js` добавлен явный путь представления **завершённого отдельного прозрачного GPU Layer Scene** для каждого Glint при выполнении всех условий:

- у кадра несколько слоёв;
- у текущего слоя основная линия скрыта;
- у слоя есть включённый проблеск;
- кадр не использует строгую GPU-only политику Spiral.

После подготовки проходов эффектов и до перехода к следующему слою такой Layer Scene переносится на основной холст с альфа-композицией, без очистки результатов предыдущих слоёв. Обычный режим с видимой линией по-прежнему использует основную схему GPU-композиции. Для строгого Spiral сохранена политика без Canvas2D-переноса.

Диагностика доступна в консоли приложения: `__somataHiddenGlintComposeStatus()` — счётчики `attempts`, `presented`, `failed` и последний `layerId`.

## Проверки

`tests/v1313-semiramida-hidden-glint-composition.js` использует только слои Semiramida из переданного пользователем плейлиста (`tests/fixtures/semiramida-hidden-glint.json`). Проверяет сохранение непустой геометрии всех трёх проблесков, независимый вызов композиции для каждого слоя, исключение при одном слое, исключение для strict GPU-only кадра и отсутствие активации нового пути при видимых линиях.

Также прошли тесты Master, Glow/Core/Halo, случайной обводки, FreezeLight и облаков.

**Ограничение:** в тестовом Chromium `navigator.gpu=false`. Путь композиции проверен с подменённым GPU-представлением, а не на реальном WebGPU-устройстве. Это отдельный защитный путь, который может быть дороже общей GPU-сцены по времени выполнения. При необходимости профилировать FPS на устройстве пользователя.

Исходный плейлист в архиве приложения сохранён без изменений; присланный пользователем плейлист использован только для выделения тестового проекта Semiramida.
